# Ekasane alpha0.00.1

Ekasane ジェネレーターの最初の実装一式です。ビルドは不要で、ファイルはそのまま動きます。

## ファイル

| ファイル | 内容 |
| :--- | :--- |
| generator.html | ジェネレーターの画面（入口） |
| generator.js | ジェネレーター本体 |
| ekasane-lib.js | ライブラリ（形式の読み書き・チェック） |
| renderer.js | レンダラー（画像の描画） |
| fflate.js | zip 展開用ライブラリ（fflate 0.8.2、MIT ライセンス） |
| ekn-sample-2.ekn | サンプルパッケージ（ステータスカード v1 ＋ 色違いパターン） |

## 置き方

- 全部のファイルを**同じフォルダ**に置いて、そのフォルダをローカルの Web サーバーで公開してください。
- `file://` で直接開くと動きません（ES モジュールと fetch の制限のため、`http://localhost` のような形が必要です）。localhost はセキュアコンテキスト扱いなので、IndexedDB などもそのまま使えます。

## 試し方

1. ブラウザで `generator.html` を開く
2. 左上の「メニュー」→「Ekasaneパッケージを開く」で `ekn-sample-2.ekn` を選ぶ
3. 「ステータスカード v1」が開き、入力欄が11件出る（名前や HP などを書き換えられる）
4. 「プレビュー」で描画を確認、「最終出力」で PNG ファイルがダウンロードされる
5. ヘッダーの「テンプレート：ステータスカード ▾」から、色違いパターン（folder2）にも切り替えられる

## 注意

- 実ブラウザでの通し確認はまだの alpha 版です。こちらでは構文チェックと部品同士のつながり（import / export、API の形、サンプルの parse）まで確認済みです。
- 動かない所や表示のおかしい所があれば、その様子を教えてください。
