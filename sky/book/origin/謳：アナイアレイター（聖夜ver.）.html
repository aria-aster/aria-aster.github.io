Chapter 1

Gifts for Ungiven

Page 1-1

祝祭の季節。
街はどこもかしこも
浅ましい煌めきに満ちている。
降り積もる雪は穢れを隠し、
灯火が人々の薄ら笑いを照らし出す。
人も天使も、 街さえ浮かれていた。
禍津姫迪子（まが がつきみちこ）はひとり喧噪から距離を置き
「幸せ」を冷ややかに見下ろす。
唇の端を、皮肉な形に歪めながら。

Page 1-2

「無知故の幸福か・・・・・・。
帝国の繁栄の足下に、どれほどの屍が
埋まっているかも知らずに」
瞼を閉じれば、いつでも蘇る。
紅蓮の炎に包まれ、疎園された故郷の景色。
私の罪と罰、私の愛した邑原（オウハラ）。
その記憶が、眼前の平和な祝祭に重なる。
帝国の祝祭など、
死者を冒涜する実である。

Page 1-3

ああ、いっそ。
すべて滅んでしまえばいいのに、
きらびやかな贈り物もご馳走り、笑顔も。
すべて吹き飛んでしまえ。
そうなったら、ああ。どんなに愉快だろう!

Page 1-4

「ねぇ、 あれ見たいなぁ」
「これ食べる! おいしそ~』
「それ買おうかな。 どう思う?』
艦を降りた天使たちも
たまの休暇に浮かれ、はしゃいでいる。
彼女らの興を削ぐのも野暮というもの
私は愛想笑いという仮面を貼り付け、
天使たちの輪から離れる。
「…？」
鼻腔をくすぐる不快な刺激に、
私は足を止めた。

Page 1-5

たった今すれ違った、軍人風の男から
嗅ぎ慣れた匂いがした。
火薬だ。
私は気配を殺し、男の背を追う。
やがて男は、人目を避けるように 街外れの廃倉庫へと吸い込まれていった。
隙間から覗けば、 そこには
赤 青 黄色に緑、
色とりどりの包装紙に包まれた贈り物（プレゼント）の山

Page 1-6

「尾けられてないだろうな?』
倉庫の中には、数名の男たち。
その所作は、明らかに軍仕込みのもの
「そんなへまはしない。
この 「花火」を
街中で咲かせるまではな』
(・・・・・・ なるほど)
私は音もなく嗤った。
彼らは、色鮮やかな包装紙の下に、
死を詰め込んでいるのだ。
明日、 この街の笑顔を悲鳴に変えるために。

Page 1-7

私が夢想した破滅を、
彼らは現実にしようとしている。
帝都の栄華は吹き飛び、
逃げ惑う人々が鮮血の花を咲かせる。
それは彼岸花のように美しいことだろう。
私はいつの間にか、
満面の笑みを浮かべていた。
「精々、 綺麗に咲かせてごらんなさい

Bone and Blood

Page 2-1

夜が明けると、
憎らしいほどの快晴だった。
「やったー!ありがとー!』
「何が入ってるのかな。 開けてみようよ!
広場では贈り物（プレゼント）を手にした子供たちが
歓声を上げる。
次の瞬間。
色とりどりの箱が次々に爆ぜ。
肉片と絶望が撒き散らされる

Page 2-2

はずだった。
帝都は昨日と変わらず、
穏やかな祝祭が続いている。
街外れの倉庫では、
警官隊が非常線を張っていた。
元軍人風の男たちが、
屈強な警官たちに組み敷かれていた。
顔は殴られたのか、
もとの顔も分からぬほど腫れ上がっている。

Page 2-3

『速報です。 ユール祭を狙った
爆弾テロを計画していたとして、 男が逮捕されました••••••』
夕闇が迫る街角。 ラジオがひび割れた音で
ニュースを垂れ流している。
通報したのは私一と言いたいところだが、 生憎と私は何もしていない。 目撃されたか、 密告か・・・・・・。 「何にせよ詰めが甘い』
阿鼻叫喚の地獄絵図が見られると、
楽しみにしていたというのに。

警告をがなり立てるラジオの傍らを
通り過ぎる。

Chapter 3

No Redemption

Page 3-1

男の子が、 満面の笑みでリボンを解く。
紅白の縞模様。
死を包んだ包装紙が剥がされる。
『 ーーッ!』

Page 3-2

思考よりも早く、身体が動いていた。
私は翼を広げて跳躍し、
男の子の小さな身体を突き飛ばし、
地面に伏せさせる。

Page 3-3

ガシャン!
乾いた音を立てて落ちた箱から
転がり出たのは、壊れた自動車の玩具。
突き飛ばされた子供は呆気に取られていたが すぐに火が付いたように泣き出した。
「なんだお前は!』
『プレゼントが台無しなのよぅ!』
両親の罵声を浴びながら、
私は泣きじゃくる子供を一瞥する。
弁解する舌などない。
私は無言のまま翼をはばたかせ。
夜空へと舞い上がった。

Page 3-4

なぜ
どうして私は、
あの子を助けようとしたのか。
夜の冷たい風が頬を打つ。
私は、自らの不可解な行動に戦慄していた。
『帝国の者どもなど、
滅んでしまえばよろしいのに!」
昨日、私は確かにそう願った。 破滅を、死を、 絶望を望んだはずだ。 それなのに、なぜ体が動いた?

Page 3-5

体は冷え切っているのに、頭の芯が熱
眼下には、祭の灯りが
宝石のように瞬いている。
あの目 我が故郷を破壊し尽くした
あめのみなかぬし
天之御中主の神獣の咆哮が。
脳裏に木霊する。
私が望んだ通り、あの神獣は
邑原のすべてを滅ぼ（アナイアレイト）した。
私の他のすべてを。

Page 3-6

私は矛盾を抱えている。
帝国の手先として働きながら、 帝国を滅ぼしたくてたまらない。
虚無を埋めるためには、 復讐を夢見るしかない。
はずだった。

Page 3-7

もし、帝国への復讐が叶ったとして。
私はどうなる?
この胸の空洞は満たされるのか?
私は空中で嘆息し、緩く瞼を閉じた。 そこに救いなどないだろう。
それでも私は止まれない。
得てしまった。 この黒い翼がある限り

Page 3-8

ブラスフェミィへ降り立つ。
艦内の空気は生温く、
張り詰めていた気持ちが不覚にも緩んだ。
「あ、アナちゃん、やっと帰ってきたべ!
ひとりだけ戻ってこないから、
心配しただよう』
「・・・・・・私ごときを待っていたのですか?」
そこにいたのは、
共に街へ降りた 「仲間」たち。
名を、何と言ったか。

Page 3-9

『当然でいす。 ほら、こっち!』
彼女に手を引かれ、
騒がしい宴席へと連行される。
暴力的なほどの光と、笑顔、笑顔、 笑顔
あっという間にパーティの帽子を被せられ、 私の両手は皿とグラスで塞がれた。

Page 3-10

「ほう、真ん中行きなよ』
「ガッハッハ、 もりもり食え!』
ぐいぐいと、人の輪の中心へ押し込まれる。
「本当に、物好きな方々ですね」
「え、なんか言った?」
「いいえ。 何にも」
いつの間にか。 私は笑っていた。
嘲笑ではない。
ほんの僅かに、口元がんでいる。

Page 3-11

何をどうしょうが、
私の罪が赦されることも。
魂が救われることもありはしない。
けれど。
孤独ではない瞬間は、確かにある。
彼岸花が群れて咲くように。
この物好きな天使たちと過ごす時間。 それだけが今、
死神の私が、生きていてもいい唯一の理由。
共にありたい。
それが、今私が持つ、
心からの願い。

Fin.
