Chapter 1

私のおばあちゃん

Page 1-1

「ごめんね・・
ごめんね、おばあちゃん」
お気に入りのアクセも、
おばあちゃんが買ってくれた服も。
食器も、家具も、私たちが帰る家も、
おばあちゃんとの思い出が詰まったものを
何もかも全部、売っちゃった。
だって、お金が必要だったから。
グレゴールの林檎を買うために、
たくさんお金が必要だったんだ。

Page 1-2

やっと手に入れた虹色に輝く林檎を
大事に抱え、夕暮れの町を駆け抜ける。
おばあちゃんに渡したら
綺麗ねって笑ってくれるかな。
それともバカねって叱っててくれるかな。
どっちでもいいんだ。
おばあちゃんの元気な声が聞けるなら。
おばあちゃん、私ね。
おばあちゃんが生きていてくれるなら、
他にはなんにもいうないんだよ。

Page 1-3

拭っても拭っても、涙で視界がにじむ。
走り続けた足は疲れて、痛くて、
息が苦しくて、心臓も張り裂けそうで。
でも、そんな苦しみなんて、痛みなんて、
おばあちゃんがいなくなることを考えたら
全然大したことじゃない。
「あっ!」
転んだ身体が宙を舞った。
林檎を落とさないようにギュッと抱える。
打ち付けられた身体が痛い。
このまま子どもみたいに大声を上げて
泣いてしまいたいくらい。

Page 1-4

「まいんちゃん。 泣かない泣かない。
大丈夫よ。 おばあちゃんがいるからね」
いつだってそう言って、
おばあちゃんは慰めてくれた。
幼い頃に両親が離婚したときもそう。
ふたりして他に好きな人ができたんだって。
私のことはいらないんだって。
けど、おばあちゃんがいてくれた。
私の味方でいてくれた。
おばあちゃんだけがーー

Page 1-5

「っ!」
歯を食いしばって再び走り出す。
おばあちゃんとの思い出は、
グレゴールの林檎になんて負けないくらい
キラキラ、キラキラ輝いている。
今でも思い出せるよ。 冬の寒い日、
両親の喧嘩が怖くて逃げてきた私に
飲ませてくれた、 甘いココアの温かさとか。
ピアノの発表会でみんなが反対するような
ド派手な服を着た私を、
おばあちゃんだけが褒めてくれて
誇らしかったこととか。

Page 1-6

おばあちゃんが私を愛して
側にいて、抱き締めてくれたから、
両親に愛されなくても、友達がいなくても、
私はずっと幸せだった。
そんな幸せがずっと続くと思ってた。
ずっと続いてほしいと願ってた。
でも、私だって分かってたよ。
おばあちゃんは私よりも
ずっと早く逝ってしまうって。
分かってたけどーー嫌だ。
嫌だ、イヤだ、そんなのいやだ!

Page 1-7

おばあちゃんが倒れた日のことは、
いま思い出しても身体が震える。
おばあちゃんが胸を押さえて苦しんで。
私は火事場の馬鹿力で
おばあちゃんを背負って
病院に連れていった。
おばあちゃんは一命を取り留めたけど、
心臓が酷く悪くて、
特効薬もないって。
ーー頭が真っ白になった。

Page 1-8

日に日に弱っていくおばあちゃん。
私にできることは、毎日のお世話。
それだけ
おばあちゃんが私にしてくれたことを
考えたら、何もしてないのと同じだ。
私はおばあちゃんのために
何かしたかった。

Page 1-9

だから、 グレゴールの林檎が必要だった。
グレゴールの林檎を食べれば、
病人だって元気になるって聞いたから。
「おばあちゃん、もう大丈夫だよ。
すぐに元気になる。
だから、これからもずっと一緒に・・・・・・」

Page 1-10

おばあちゃんは助かるはずだった。
それなのに一
おばあちゃんのベッドには、
一握りの灰と。
虹色の林檎が転がるだけ。
「・・・・・・どうして?」
グレゴールの林檎を食べれば、
おばあちゃんは
助かるんじゃなかったの?
「あ、あ、あああああ!」
絶叫が、おばあちゃんの消えた寝室に
響き渡った。

Chapter 2

ただ、死んでないだけ

Page 2-1

現実なんてくそ食らえ。
声も涙も涸れ果てた。
心は涙と一緒に流れて、
私の中は空っぽだ。
どんなに泣きわめいても
目の前の現実は変わらなかった。
おばあちゃんは灰になって死んだ。
グレゴールの林檎を食べたせいで。
ーー私が殺した。

Page 2-2

おばあちゃんの部屋は
いつだって優しさに満ちて暖かかったのに、
今は暗くて、冷たくて、寂しい。
私はベッドの傍らにへたり込み、
おばあちゃんだった灰を
ただ、ぼんやりと眺めていた。
世界って、
こんなにも静かに壊れちゃうんだ。
ううん。 私が壊した。
私がバカだったから。
だから、おばあちゃんは死んじゃったんだ。

Page 2-3

「ーーああ、そっか。 私なんか、
もっと早く死んでおけばよかったんだ」
両親にいらないと言われた目に
おばあちゃんに泣きつかずに
死ねばよかった。
そうすれば、おばあちゃんは
こんな死に方をしないですんだ。
身体も魂も粉々になって死なずにすんだ!

Page 2-4

「おばあちゃん・・・・・・ごめんなさい」
灰の中で輝く、 かじりかけの林檎を拾う。
これがこうして残ってるってことはさ。 お前も死ねって、そういうことだよね?
「おばあちゃん。 私もそっちへ行くよ」 おばあちゃんのいない世界に
未練なんかない。
林檎よ、お願い一
私をおばあちゃんのところに
連れていって。

Page 2-5

[ページ種別：青]
“パパ”と“ママ”と”妹”が、
“私”の大好きな
ピカピカの笑顔で笑ってる。
ーー遺影の中で笑ってる。
不思議な匂いが鼻をついた。
線香の匂いだ。 “私”は知ってる。
呪文を唱えるような読経の声が、
酷く遠くに響いて聞こえた。
私はひとりぼっち。
見知らぬ夢の中でも、ひとりぼっち。

Page 2-6

[ページ種別：青]
奇跡の生還者ーーそれが、家族の命と
引き換えに得た。 私の称号。
家族旅行から帰る途中、飛行機が墜ちた。
生存が絶望的なその事故で
唯一生き残ったのが私だ。
重傷を負ったはずなのに、
助け出されたときには、
まるで何事もなかったかのように
無傷だった私。
強靭な身体に
驚異的な回復力と生命力って
お医者さんが言ってた。
何だよ。それ。バケモノじゃん。

Page 2-7

[ページ種別：青]
マスコミは同情するフリをして
私のことを面白おかしく書き立てる。
事故の犠牲者の家族が私を責めた。
何の関係もない世間（SNS）の人たちまでも。
まるで私が何か悪いことをしたみたいに。
親切ぶった人は言うーー
家族の分も強く生きるんだよ、なんて。
でも、なんで？
私を愛してくれた人はもういないのに。
私だって死にたかったよ。
みんなと一緒に、死にたかった。

Page 2-8

[ページ種別：青]
夜の渋谷の街をひとり歩く。
遅くなると、パパとママが心配したっけ。
ーーでも、もう誰も私を叱らない
街は眩しくて、うるさくて。
ひとりぼっちの私に見向きもしない。
その無関心さに救われてるのに、
孤独は冷たく、重たくまとわりついた。
「はぁ ・」
なんか、疲れちゃったな。

Page 2-9

[ページ種別：青]
交差点の信号が赤に変わって足を止めた。
通り過ぎていく車のヘッドライトが、
光の尾を引いて川のように流れていく。
後ろでふざける酔っ払いが。
私の背中にぶつかった。
踏ん張れば十分耐えられるけどーー

Page 2-10

[ページ種別：青]
もういいか。もういいや。
ふらりと車道に飛び出た私を、
真っ白なヘッドライトが目映く照らした。

Chapter 3

もう傷つかない

Page 3-1

[ページ種別：青]
「なにしてんのよ！ バカ」
強く腕を引かれ、
クラクションを鳴らした車が
鼻先を通り過ぎていく。
尻餅をついた私は、
ぽかんと声のほうを見上げた。
子供の頃にテレビで見ていた。
戦う女の子のような
格好をした女の人が。
肩をいからせて私を見下ろしていた。
その目が鋭く別の方向へと向けられる。

Page 3-2

[ページ種別：青]
「そっちの酔っ払い!アンタたちも
こんなところでふざけるんじゃない!
人殺しになりたいわけ!?」
きっと、私にぶつかった人たちだ。
彼らは首を竦めて、青に変わった信号を
そそくさと渡っていく。
「おいこら、逃げんな! ーーったく。
大丈夫? 立てる?」
差し伸べられた手を
戸惑いながら掴む。
私と変わらない小さな手は、
力強く私を引き上げた。

Page 3-3

[ページ種別：青]
「危ないなと思って見てたけど、
あいつらがぶつかったあと、
自分で飛び出したよね?
死にたいの?」
死にたかったわけじゃない。
でも、どうでもいいと思っていたーー
そんな言葉が、 ポロリとこぼれた。
「バカ! 命を粗末にすんな!
あんたが死んだら
誰が悲しむと思ってるんだ!」
いないよ。 悲しむ人なんて、もう誰も。
喉に詰まった言葉の代わりに、
ただ、涙が溢れた。

Page 3-4

[ページ種別：青]
「そっか・・・・・・ あんたが、あの」
ファミレスで私の話に耳を傾けていた
彼女、 甘奈さんは、深々とため息をついて
テーブルに突っ伏した。
「ごめん。 知らなかったとはいえ・・・・・・」
「ううん、いいの。
その・・・・・・助けてくれて、ありがとう」
誰かとこんなに話をしたのは久しぶりだ。
少しだけ胸が軽くなった気がした。
まともな会話に飢えていたのかもしれない。

Page 3-5

[ページ種別：青]
「今思うと、 車とぶつかっても
死ななかったと思うんだ。
飛行機事故でも死ななかったくらいだし」
人よりうんと頑丈なの――そう言った私に、
甘奈さんは悲しそうに眉を下げた。
「そうだとしても、痛いでしょう
死ななきゃいいってワケじゃないよ」
甘奈さんの言葉に、また涙が込み上げた。
「よし、決めた。 友達になろう、まいん」
私がバカなことをしたら叱ってくれると
彼女は笑った。

Page 3-6

[ページ種別：青]
「もう知り合っちゃったんだ。
この先、まいんが死んだら、 私は悲しい。
だから生きよう。
一緒にこれからのこと考えようよ」
一緒に一
ああ、 なんて眩しい人なんだろう
「うん······っ、うん!」
てらいなく差し出された手に、
私はすがるように手を伸ばした。

Page 3-7

ーー伸ばした手は空を掻いた。
指先におばあちゃんだった灰がかすめる。
現実に戻ってきてしまった。
おばあちゃんを殺した林檎を食べたのに、
何で私は生きているんだろう。
背中には真っ白な翼が生えている。
天使の翼だ。 私は天使になったんだ。
「どうして? おばあちゃん・・・・・・」
あの夢は何?
おばあちゃんは、何を伝えたかったの?

Page 3-8

分からない。
生き延びたのは、
おばあちゃんを死なせた
バカな私への罰なのかな。
ーそうかもしれない。
でも、夢の中で胸を震わせた目映い光が
今も孤独な心を照らしてくれているから。
「決めたよ、 おばあちゃん」
枯れたと思った涙が溢れる。
その涙を強く拭い。 私は立ち上がった。
たとえ、おばあちゃん殺し（背負った十字架 ）が
どれほど重くとも。

Page 3-9

「あの子みたいに、なってやる」
孤独な誰かを救う、強くて眩しい存在に。
おばあちゃんを殺したこの手で、
今度は誰かを救ってみせる。
窓の前に立つ。 夜明けの空が鮮やかな
朝焼けに色づいていた。
窓を開け放てば、
爽やかな風が吹き込んだ。
おばあちゃんだった灰が風に飛ばされ
幻のように消えていく。

Page 3-10

私は寂しさをぐっと堪え、
空っぽの部屋に向けて精一杯笑ってみせた。
「おばあちゃん、 行ってきます」
ーー行ってらっしゃい。
窓から飛び立つ私の背中を、
軽やかに笑うおばあちゃんの声が
優しく押してくれた気がした。

Fin.
