「よく来てくれた、 パンドラ」 「はあ・・・・・・」

『これよりパンの一族緊急会議を

海の家限定のパンだよー☆』
エクスカリパンは架空のカメラに向かって
ウィンクを決める。
潮風に吹かれながら食べるパン。 想像しただけで、心は一次発酵を 終えた生地のようにムクムク膨らむ。 さあ、どんなパンと出会えるかな!

海の家に普通、パンはない。
その事実をつきつけられ、
エクスカリパンの発酵は止まった。
「なぜ海には、 パンがないの・・・・・・?
海パンはあんなに売っているのに
なぜ本物のパンが
ひとつもないんだッ!』

Page 1-6

「・・・・・・ というわけなんだ』
エクスカリパンがパンドラの手をとる。
「そう言われましても・・
パンと海は相性があんまり良くないのかも
パンドラが困惑する。
「パンだよ!? いつだって、どこだって、 あたしたちを包んでくれるパンだよ!? 海で食べたくならないなんて、嘘だッ!」 エクスカリパンは泣きながら訴える。
『そう思ってるのは、世界中で
エクスカリパンさんだけだと思います」

ショックのあまり、エクスカリパンの
サングラスがパリンと砕けた。
『エクスカリパンさん。
元気出してください。
パンがなくても、海は楽しいですよ。 普通に海で遊びましょう』

Page 1-8

でも、このままじゃダメなんだ・・・・・・』
エクスカリパンは曇りのない瞳で
パンドラをみつめる。
『海で食べるパンが、 どれだけ自由で、
どれだけ人を幸せにするのか・・・・。
みんなに知ってほしい。
いや知るべき!』

Chapter 2

寿司ならある

Page 2-1

「はーい、みなさん!
焼きたてのパンはいかがですかぁ~?』
エクスカリパンは海辺にパンの家を 焼き上げた。 柱はバゲット、壁は食パン、 屋根はクロワッサン。 ドアノブはマフィン。 小麦の香りに包まれた素敵なパン屋さんだ。
(ふふふ、みんなこっちを見てる。 やっぱり、海にはこれくらいの
インパクトが必要だったんだよ!)

Page 2-2

しかし一
エクスカリパンの期待とは裏腹に、
パンは全く売れない。
他の海の家は大賑わいだと言うのに。
「このままじゃ経営が傾いちゃう・・・・・・ ていうか、パンの家も傾いてる?」
足下がぐっと沈み込む。パンの床から
じわっと水があふれてくる。
「何これ!? 浸水!?』
みるみるパンの家がふやけていく。
気付けばパンの家に
波が押し寄せていた。

Page 2-3

「潮の満ち引きとか考えてないんすか」
眺めていた見物人が苦笑する。
これが、 満ち潮!
エクスカリパンには海がわからぬ。
エクスカリパンは、パン殺者である。
手塩にかけたパンの家が沈んでいく。
気づけば魚たちが
パンの家を自由に泳ぎ、
ふやけたパンをつついていた。
「・・・・・・あたしのパンを食べてくれるのは、
この子たちだけ......か」

Page 2-4

エクスカリパンが沈む家を眺めながら
涙をぬぐっていると一
『よお。 活きのいい魚だな。
寿司握ってやろうか!』
さっそう
太陽を背負い。 颯爽とスシエルが現れた。
『やめて! この子たちは
あたしのお客さんなんだよ!!』
慌ててスシエルを止める。

Page 2-5

スシエルは、いつになく真面目な顔で
片眉を上げた。

Page 2-6

「バッカヤロー!!』
「うごぐっ!?」
事情を全て話すと、いきなり口の中に
あきら
寿司をぶち込まれた。
「諦めんな! 諦めんなよお前
売れないなら工夫しな! 前に私が言ったことを忘れたか!
「・・・・・・ゴクン! ・・ ハッ・・・・・・!』
(そうだ。 あたし、大事なことを忘れてた。 お客さんの気持ちに寄り添えないヤツは
料理人失格だってスシエルが言ってたのに)

Page 2-7

「あたし、海の家にパンがないことを嘆いて
押し売りするだけのパン屋に成り果ててた」 大事なのは、
食べる人の気持ちなのに。
エクスカリパンは顔をあげ、
スシエルをみつめる。
「目に光が戻ったな。
それでこそ私のライバルだ」
スシエルはキランと歯を輝かせた。

Chapter 3

パンしかない!

Page 3-1

「ええ〜!もう店じまいかよ。
あたし、腹がペコちゃんなんだけど!』 やってきたハーキュリーが肩を落とす。
「パンの家が・・・・・・ まるで、 お粥みたい····· パンドラが心配そうに見つめる。
「パンは全部、飲んじゃった。
残ってるのは、 スシエルが握ってくれた お寿司と、 非常用のバゲットだけ・・・・・・』
力なく笑うエクスカリパン。
「そうだ! エクスカリパンさん!』
パンドラは名案を思いついた。

Page 3-2

『パンでお家を作れるなら、
お皿を作るのはどうです?
パンのお皿に焼きそばとか
焼きイカを乗せて売るのはどうですか?」
パンドラの提案に
ハーキュリーがうなずく。
「そいつはいいな。 海の家っぽいし』
『パンは、お皿じゃなくて主役だもん
脇役に甘んじるパンなんて、
認めないッ!』
エクスカリパンはダダをこねた。

Page 3-3

『パンでお家を作れるなら、
お皿を作るのはどうです?
パンのお皿に焼きそばとか
焼きイカを乗せて売るのはどうですか?」
パンドラの提案に
ハーキュリーがうなずく。
「そいつはいいな。 海の家っぽいし』
「パンは、お皿じゃなくて主役だもん!
脇役に甘んじるパンなんて、
認めないッ!』
エクスカリパンはダダをこねた。
「なんかごめんなさい・・・・・・』
「気にすんな。 こいつが面倒なだけだ」 パンドラをハーキュリーが
フォローする。

Page 3-4

「でも······ そのこだわり、嫌いじゃないぜ。
乗っかってやんよ!』
スシエルは巨大な包丁を抜いた。
「ありがとうスシエル!
パンと寿司がひとつになれば、 砂浜の王者になれるよ!』

Page 3-5

「大丈夫かな・・・・・・。 この前ふたりで作った
「フグ寿司ドッグ」 は、 パッサパサで
正直おいしくなかったけど...』
パンドラが冷静に釘を刺す。
「いいアイデアを
思いついたんだ。 ハーキュリー 火を起こしてもらえるかな?」
『オッケーまかせろ!』
「パンドラ! この野菜を切ってくれ!」
「は、はい!」
「スシエル!
さっきのお寿司をちょうだい!』
「あいよ! 活きのいいサバだぁ!』

Page 3-6

エクスカリパンは受け取った寿司から、
ネタのサバをひらりとはがす。
シャリを食べつつ、サバを炭火にON!
ジュ、ジュワー!!
炭火の上で、脂ののったサバが
香ばしい煙を上げる。
サバに、スライスしたタマネギとレタス、 酸味の効いたレモンとマヨネーズを加え、 バゲットで力強くサーンドッ!
「できた!
「海サバサンド」 一つ☆」

Page 3-7

『う、美味そう! 食わせろッ!』
ハーキュリーがサンドイッチを奪い取り、
真っぷたつにすると
半分をパンドラに渡す。
ハーキュリーとパンドラが、
大きな口でサバサンドにかぶりついた。
「・・・・・・ う うめえええええ!!』
「おいしいー!」

Page 3-8

「炭火で焼いたサバの脂と、レモンの酸味
パンの歯ごたえというマットの上で 完璧にプロレスしてやがる••••••!!』
「おいしいです! お魚とパンって、 こんなにも仲良しだったんですね』 パンドラも夢中で食べている。
「やるじゃねえか、エクスカリパン!
私のサバ寿司が、 こんな姿に化けるとはな」
「スシエルのおかげだよ。 ありがとう!」
スシエルがエクスカリパンと
固い握手を交わす。

Page 3-9

『さあ、じゃんじゃん作るよ!』
『サバ寿司は任せな!』
スシエルがサバ寿司を握り、
エクスカリパンがネタ（サバ）をはがす。
ハーキュリーがサバを焼き、 エクスカリパンがシャリを食べる。
(寿司を握る工程いるのかな?)
パンドラは疑問に思いつつも
野菜をカットして、
エクスカリパンがバゲットに
サバと野菜をサンドイッチする。
完成☆

Page 3-10

しばらくして
『くつ。腹がシャリではち切れそうだ』
「がんばれエクスカリパン!」
スシエルがサバ寿司を握りながら応援する。
「負けるな! あたしめシャリを食うから
ハーキュリーもシャリを口に詰め込む。
(シャリは置いておけば いいんじゃないかな・・・・・・)
パンドラの疑問はつきないが、
楽しそうなのでそのままにした。

Page 3-11

香ばしい匂いに誘われて、
ビーチの人々が次々と集まってくる。
「なんだあのパン!」 「超うまそう!』
「忙しくなってきたぞー!』
エクスカリパンは、パンの一族を呼び集め
サバサンドを作りまくった。
『パンの一族?何の話ですか?』
デスパンチはなぜ自分が
パンの一族なのか分からないまま。
サバを焼かされ、
シャリだけを食べさせられる。
「いらはいいらはい! 海の幸、
サバサンドや!』
デスパンチの相棒、 ファイブが
呼び込みをすると店は大繁盛

Page 3-12

みんながエクスカリパンのパゲットと
炭火で炙ったスシエルのサバのマリアージュに
笑顔になった。

Page 3-13

「・・・・・・ふう!
みんな、本当にありがとう!』
エクスカリパンはパンの一族と、 最高の仲間たちに向き直った。
『ハーキュリーも今後は
パンキュリーと名乗るがいいよ』
「うん。 お断りだ」
「みんなのおかげで······ あたし、 パンをピーチに
届けることができたよ。
ひとりじゃ、ふやけて終わってた......」

Page 3-14

「よせやい。 あたしは
ただ美味いメシが
食いたかっただけだぜ!』
ハーキュリーが照れくさそうに笑う。
「ふふふ。一時はどうなるかと
思ったけど良かったです』
パンドラが微笑む。
「なんだか知らないけど良かったね』 ファイブとデスパンチは
困惑しつつも笑顔になった。
スシエルがエクスカリパンの肩を抱く。
「これでお前も、海の料理人だな!』

Page 3-15

ふっくらと焼き上がるパンのように
エクスカリパンの胸があたたかくなる。
(あたしはやっぱり、パンが好き。 パンで人を笑顔にすることが、 世界一大好き!!)
