Chapter 1

英雄の妹

Page 1-1

「姉さん............どうしたのかな・・・・・・」
ディ・メテルは落ち穂を拾いながら、
ぽつりとつぶやいた。
戦争に行った姉、 ラビ・メテルから
長いこと手紙が届いていない。
今も、戦地で華々しく活躍し、
手紙を書く暇もないのだろう――
両親はそう言う。
毎月、姉から入金があるから。
戦死したわけではないと思うのだけど...。
ディは心配だった。

Page 1-2

姉は一兵卒ながら、 幾度も武勲をあげ、
英雄と讃えられた。
世間から顧みられることのない
貧農の家から、 姉のような英雄が出たことは
一族の誇りだった。
末っ子のディにとって、
年の離れた姉ラビは憧れであり目標だった。
ラビからの手紙を繰り返し読み
武勇伝に心を躍らせた。
だからーー
「私も姉さんみたいな軍人になる」
両親にそう宣言し、半ば家出するように
ディは帝国陸軍へと飛び込んだ。

Page 1-2

「お前、あのラビ・メテル少尉の妹か!」
行く先々で、みんなが口にする。
あの戦いはすごかった。
あの時は助けられたーー
数々の逸話を聞くたび、
ディは誇らしい気持ちになる。
なのに、いつまで経っても
姉の消息は知れなかった。
やっぱり何か変だ
話を聞かせてくれる軍人たちも、
姉の消息を知らなかった。

Page 1-3

「ディ・メテル。 司令部へ出頭しろ。
ラビ・メテルに会わせてやろう」
機会はある日突然やって来た。
厳しい訓練に耐えてきた
ご褒美かもしれない。
やっと姉に会える。
期待に胸を膨らませ。
ディは司令部へ向かった。

Page 1-4

ディが通された部屋の中央では、
得体のしれない白い物体が、
金属のベッドに乗せられていた。
「これは・・・・・・何でしょうか」
おそるおそるディが尋ねる。
「彼らが軍神ラビ・メテルだ」
厳しい顔の上官がそう告げた。
ディはぽかんと、それを見る。
ぐるぐると包帯を巻かれた。
芋虫のような、サナギのような物体。
これが、 姉であるわけがない。

Page 1-5

「ラビ・メテルは前線で四肢を失い、
目も耳も潰れてしまったのだ。
まさしく英雄に相応しい戦いぶりだったよ」
上官の言葉に、 ディの血の気が引いた。
では、この包帯の中身は、何も見えず。
聞こえず、手足さえ持たない姉なのか。
「姉さん······?」
サナギは、ディが呼びかけても、
何の反応も返さなかった。

Page 1-6

「安心しろ。 軍神ラビ・メテルは、
天使となって蘇るのだから」
上官は説明を始めた。
グレゴールの林檎、というものがある。
口にしたものは天使として生まれ変わるが、
運が悪ければ灰となって死ぬ。
英雄ラビ・メテルならば
必ずや天使となるだろう。
「失った手足も目も耳も元通りとなり、
軍神は翼を得て再び戦場へ舞い戻るのだ」
上官は熱く語った。
姉さんの身体は元に戻るんだ。
それを聞いて、ディは胸をなで下ろした。

Page 1-7

「天使に志願し、 林檎をかじってから、
結構な時間が経ってしまった。
君の声を聞かせてやれば目を覚ますかもしれん」
上官の言葉に従い。
ディは姉のもとに通った。
物言わぬ、身動ぎひとつしない姉の
丸い身体にそっと抱きついて頬をよせ。
想いを込めて言葉をかける。
「頑張って天使になってね、 姉さん。
私と一緒に、帝国のために戦おう」

Page 1-8

ある日、
サナギの中から応えるように、
トクンとひとつ、鼓動が聞こえた。
天使になるんだ。 ディは歓喜した。
姉にディの言葉が届いたのだ!
ディは固唾を呑んで羽化を見守った。
ふわりーー風を抱いていたように
柔らかくサナギがほどける。

Page 1-9

「・・・・・・え?」
サナギの中からこぼれ出たのは、
乾いた灰だけだった。

Chapter 2

灰になった英雄

Page 2-1

「・・・・・・姉さん?」
ディ・メテルは震える手で灰をすくった。
さらさらと指の間をこぼれていく。
ヒトひとり分の灰の山。
「うそ・・・・・・嘘だ! そんなの嘘!
姉さんが天使になれず、
灰となってしまったなんて。

Page 2-2

「やだ······ いやだ、やだよ、 姉さん!」
かき集めればかき集めるほど、
灰の山は崩れて、散っていく。
「姉さん、 姉さん! うううう......」
灰を抱き締めるように突っ伏したディの額に
冷たく堅い何かがぶつかった。

Page 2-3

「林檎・・・・・・?」
灰の山から虹色の林檎をすくい上げる
グレゴールの林檎だと、すぐに分かった。
姉の命を吸い取ったかのように
美しく輝く林檎に触れて初めて、
ディは理解した。
姉は戦いたくなどなかったということを。
英雄にもなりたくなかったし、
天使なんかにもなりたくなかった。
なのにーー

Page 2-4

「あいつらだ」 低く咒（のろ）うように呟いて
ディはきつく唇を噛み締めた。
志願したって?
目も見えず、耳も聞こえなかった姉に
天使になるかなんて、どう聞いた?
姉がどうやって答えられた?
姉は何も分からないまま
林檎をかじらされたのだ。
英雄を押しつけられたのだ。

Page 2-5

ディは歯を食いしばり、うずくまった。
そうしなければ、 身体の中に渦巻く激情が
爆発してしまいそうだったから。
ごめん······ごめんね、姉さん。
英雄を押しつけたのは、ディも同じだ。
姉なら天使になれると盲目的に信じていた。
分かってあげられなくてごめん。
天使になんてなりたくなかったのに、
頑張ってだなんて言って、 ごめんなさい。
「でも私は・・・・・・
もう一度、姉さんに会いたかったんだよ」

Page 2-6

ディは涙でぐちゃぐちゃになった顔で
グレゴールの林檎を見下ろした。
「ーー姉さん?」
林檎から、姉の息づかいが
聞こえた気がした。
天使にならなかった姉は、
灰になってしまった姉の魂は、
どこに行ってしまったのだろう?
「姉さん、 そこにいるの?」
会いたいよ、と涙を流しながら、
ディは林檎をそっとかじった。

Page 2-7

[ページ種別：青]
ただ、悲しみだけがあった。
何も見えない、何も聞こえない闇の中。
心の奥底から湧いてくる破壊衝動が、
森の奥に封印された 「怪物」の
長い、長い眠りを覚ます。
絶叫のような咆吼が大気を震わせる。
怪物は何もかもを飲み込んだ。
人を、 街を、 希望を、 未来を。
飲み込んでは吐き出し、
吐き出しては踏み躙り
死と、瓦礫と、 絶望と、破滅の轍を刻む

Page 2-8

[ページ種別：青]
ーーこの破壊衝動は何だろう。
ディ・メテルは他人事のように思った。
何も見えない。何も聞こえない。
ディが漂う暗闇は、怪物の心の中だ。
何もかも引き裂くような絶叫。
怪物は泣いていた。
自分を愛してくれた人に会いたいと、
生まれた場所へ戻りたいと泣きながら、
怪物は涙の代わりに災厄を振りまいた。

Page 2-9

[ページ種別：青]
会いたい。恋しい。 帰りたい。
姉さん、姉さん、姉さん怖いよ。
怪物とディの心が重なり合う。
怪物（ディ・メテル）は咆吼を上げた。
悲しみは湧き上がる破壊衝動に飲み込まれ、
ただ破壊の限りを尽くす。
どれだけ破壊しても満たされない。
満たされるはずがない。
欲しいものはここにはないから。
怪物は、止まれない。

Chapter 3

天使ディ・メテル

Page 3-1

[ページ種別：青]
怪物はバラバラになった。
神性を持つ双つの剣に討ち取られ、
災厄を振りまいた邪悪に相応しく無残に散った。

Page 3-2

[ページ種別：青]
痛みはなかった。 苦しみはなかった。
恐怖も、絶望もなかった。
ただ、 やっと終わるのだと、
湧き上がる破壊衝動から解放されるのだと、
怪物は最期、安堵の咆吼を上げた。

Page 3-3

[ページ種別：青]
ふたりの少女が怪物の身体を切り裂いたとき
ディ・メテルもまた。
怪物と共にバラバラになった。
結局、何も分からないままだった。
あの怪物は“何”で、“なぜ”林檎は
ディに怪物の記憶を追体験させたのか。
(・・・・・・どうでもいいか、そんなこと)
ディは思考を手放した。
怪物の命が尽きるとき、
ディの命もまた尽きるのだ。

Page 3-4

[ページ種別：青]
「わたしも、
あなたに会いたかったよ」
懐かしい声が途切れかけた意識を繋ぐ。
姉の声だった。
間違えるはずがない。

Page 3-5

[ページ種別：青]
「姉さん! 姉さぁん!」
心のまま、子供のように泣き叫ぶ。
暗闇の中、小さな光がゆっくりと明滅した。
ディは光に手を伸ばした。あれは姉の魂だ。
光に触れた指先から、
温もりが全身に広がっていく。
今にも消えそうな光を逃さぬように、
ディは必死に姉の魂を胸に抱き締めた。
姉の思いがジンと染みこんでくる。

Page 3-6

[ページ種別：青]
「会いたいって思ってくれてたんだね。
だから、姉さんは……っ、だから!」
姉はーー英雄であったラビ・メテルは、
最後の最後に自我を貫いた。
ラビの願いはただひとつ。
ディと再会すること。
それが叶ったから灰になったのだ。
だから、 天使にならなかったのだ。

Page 3-7

[ページ種別：青]
四肢を失っても、
目と耳が潰れても
妹に会いたかったから、
あんな姿で生きていてくれた。
ラビはただ ラビ・メテルとして死んだ。
英雄ではなくて、ディ・メテルの姉として。
そうして姉は、ディの元へ帰ってきた。
姉はやっと、自由になったのだ。
「――ディも自由になっていいんだよ」
姉の温もりを感じる目映い光が、
優しくディを包み込んだ。

Page 3-8

その耳障りな歓声は、
まるで怪物の咆吼のように
ディの眠りを妨げた。
ぼんやりする頭を振りながら身を起こし、
ぐるりと視線を巡らせる。
そこには自衣や軍服を着た
人、ひと、ヒトー
「軍神の妹が天使になった!」
「新たな英雄の誕生だ!!」
ああーそういうことか。
ディ・メテルは両手を見つめた。

Page 3-9

姉さん、私は選んだよ。
自由になっていいと姉は言った。
これが、 ディの選んだ自由だ。
ーーラビがならなかった天使になること。
けれどそれは、
英雄になりたいからじゃない。
姉の代わりになりたいからでもない。
ディは身震いするように翼をはためかせた。
巻き起こる風に、おお、と響く中、
研究者たちに背を向ける。

Page 3-10

姉の輝かしい功績を否定はしない。
けれど、戦いがある限り
望まぬ人生を送る人がいる。
自由を失う人がいる。
涙を流す人がいる。
そんなのは、もううんざりだ。
ディが天使になったのは、
人と人の戦いを終わらせて
人々を解放するため。
そうして初めて、 英雄と祭り上げられた
姉の魂は自由になれる。

Page 3-11

「見ていて、 姉さん」
追いすがる人々を置き去りにして
研究所を出たディは、蒼穹を見上げる。
「英雄を必要とする戦争なんか、
私が終わらせるから」
すべてのしがらみを振りほどくように
ディは大きく翼を羽ばたかせた。
力強く大空へと舞い上がる。
ここからは、 英雄（ラビ・メテル）の妹ではない。
