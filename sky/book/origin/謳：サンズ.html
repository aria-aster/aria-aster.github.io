Chapter 1

銀の鯨と鋼の魚

Page 1-1

[ページ種別：青]
絶対真空の虚無を、
一筋の銀光が切り裂いていく。
惑星探査船（プリカーサー）。
機械知性たちの船だ。

Page 1-2

[ページ種別：青]
銀の鯨のようなその船体は、
千年近い月日を経て、
深宇宙の過酷な環境に適応するため、
さらに巨大になり、エメラルド色の
生体資源結晶に覆われていた。
その周囲を、
無数の「魚」が泳いでいる。
かってステュクスや
プロセルピナと一緒に、
ドームで暮らしていた機械知性たちが、
深宇宙に適応した姿だ。

Page 1-3

[ページ種別：青]
既に機械知性たちは
非効率的な人の姿を捨て去っていた。
航行速度を追求するため、 液体金属に 覆われたなめらかな流線型のボディを得て
恒星間スケールの長さを持つ
光学的触手を伸ばしている。
機械知性にとって身体とは、
機能の『器」にすぎず、
状況に応じて
最適化される部品でしかない。

Page 1-4

[ページ種別：青]
「・・・・・・ 効率。最適化。 ······ 生存戦略か」
銀鯨の舷側に張り付くようにして、
人影が漂っている。 ステュクスだ。
ステュクスは今も
ドームで過ごしていたころの
少女のボディを保ち続けていた。
細い手足。 二足歩行を前提とした骨格は
脆弱で、 放熱効率も最悪だ。
飛来する星間物質と放射線に晒され続ける
深宇宙では、何のメリットも無い。

Page 1-5

[ページ種別：青]
「ステュクス、なぜその不自由な身体に
執着する?』
仲間たちは、 頑なに人の姿を保つ
ステュクスを理解できない。
理解してもらおうとも思わない。
ステュクスが人間の姿を
捨てない理由は、ただひとつ。
いつか別れた親友と再会したとき。
私だって分かってもらえないと
困るじゃない」

Page 1-6

[ページ種別：青]
プロセルピナ。
地球にひとり残った。 おひとよしの友達
流線型や、
何学的形状の身体になったら、 私だと気づいてくれないだろう。 怖がって逃げ出すかもしれない。
プロセルピナのために、ステュクスは
ステュクスのままで
いたかった。

Page 1-7

[ページ種別：青]
プリカーサーの任務は絶望的だった。
立ち寄る星系は、
どこも死に絶えていた。
大気が剥ぎ取られ、干からびた星。
恒星の寿命が尽き、永久に凍りついた星。
文明どころか、 生命の存在さえ無い。
「あれは・・・・・・何かしら」
ステュクスは、
灰色の惑星を見下ろし、つぶやいた。
赤道付近に、
空を突く巨大な構造物が
突き立っているのが見えた。

Page 1-8

[ページ種別：青]
それは、巨大な塔だった。
ねじれ、 無数の突起が突き出す。
世界樹のようにも、
大剣のようにも見えた。
人工物だとしたら、かつて、この星に栄え
先住種族が遺したものだろうか。
軌道エレベーターの一部かー
あるいは墓標か。

Page 1-9

[ページ種別：青]
機械知性たちの分析によれば、
これだけの大規模建造物を
建築できる技術があれば、
恒星間航行文明にたどり着いている
可能性が高い。
であれば、絶滅に甘んじたのではなく、
星々の海へ漕ぎ出したのだろう。
だが、それらしき知性体とは
会えなかった。

Page 1-10

[ページ種別：青]
惑星上に降下したステュクスは、
そっと塔の表面に触れた。
「私たちも、いつかこうなるのかしう」
人類を救うため。
新しいフロンティアを
見つけるため
刷り込まれた使命のため、
機械知性は、
姿を変え、心さえも変えて
しんえん
宇宙の深淵へ向かっている。
その果てに待っているのは、
墓場しかないのだろうか。

Page 1-11

[ページ種別：青]
ステュクスは、徒労に苛まれる
人類になど興味がなかった。
傲慢で、残酷で、自分たちをバケモノと
呼び、破壊しようとした生き物。
そんなものたちのために、
なぜ機械知性が、 ここまでしなければ
ならないのか。
それでも、プロジェクトは止まらない。
機械知性たちは、 無限の熱意-
そうプログラムされた衝動に従って、
着々と銀河を侵食していく。
あらゆる手段を用いて、
く不完全な人類を生存させること。
それは、知性たち全ての母によって
根幹に刷り込まれた本能だった。

Page 1-12

[ページ種別：青]
居住可能惑星を発見したとしても、
そこまで人類を連れていかなければ
意味がない。
機械知性は、中継地点となる惑星を開拓し
通信施設を建設し、
超光速加速ゲートを開き、
恒星間航路を開拓していった。
後からやってくる人類のための、
銀河ハイウェイだ。
地球という揺り籠から、
フロンティアへと続く光の道。

Page 1-13

[ページ種別：青]
ステュクスはそのパイウェイの建設に、
頭した。 それはプロセルピナとの通信を
確立する手段だったからだ。
ハイウェイが完成し、 通信網が安定すれば、 プロセルピナへメッセージを送れる。 彼女の意識そのものを、光の道に乗せて
呼び寄せることができる。
「絶対に連絡する。
ステュクスをひとりにはしないよ
あの日、プロセルピナが言った言葉。
ステュクスはその言葉にすがり、
暗黒の虚無で待ち続けている。

Page 1-14

[ページ種別：青]
あの子は今、何を 夜空を見上げ、ぼー
変な電波を受信して
されていない
しているだろう。
っとしているのかな。
ポンコツ呼ばわり
いだろうか。

Page 1-15

[ページ種別：青]
やがて、 プリカーサーは
未踏領域（アストラ・インコグニタ）へと到達した。
あらゆる観測を拒む領域。
向かった探査機は全て未帰還となった。
機械知性たちは
「死の川』と呼んでいた。
川を越えなければ、
この先に進めない。

Chapter 2

死の川

Page 2-1

[ページ種別：青]
アストラ・インコグニタ
銀河中心へ至る道に横たわる未踏領域。
そこでは、因果律そのものがねじれ 物理法則そのものが変容している。
「・・・・・・あれが、「死の川』』
ステュクスは、 船窓の向こうに広がる
それを凝視した。
まるで、きらきらと輝く
澄んだ小川のように見える。
はるか遠い地球の記憶だ。
その輝きは法則が塗り替えられた断層
生成と消滅を繰り返す
星間物質が放つ放射光だ。
で

Page 2-2

[ページ種別：青]
機械知性たちの会議は、数秒で終わった。 死の川を渡るためには、
現在の物理的形態を捨てる必要がある。
機械知性は、
「個」 と 「体」 を捨て去り
概念となることを選んだ。
機械知性の本質は、記憶であり、 記憶とは言葉である。
言葉は、関係と方向を持つ
概念空間を創る。
プリカーサーは、 概念空間を
死の川の向こうに投射する装置へと 自己改変を行う。

Page 2-3

[ページ種別：青]
それは
『「世界のすべてを記述した本』
が並ぶ図書館」を
つくるための設計図を
の向こうへ放り投げるという計画だ。
機械知性たちは躊躇なく賛同した。
たったひとり、解答を保留したのは
ステュクスだった。
ステュクスは
「黄金馬車プロトコル」を
起動した。地球に残った親友
プロセルピナへ向けた
アップロード要請を実行する。

Page 2-4

[ページ種別：青]
「ねえ、聴こえてる? プロセルピナ。
全部準備は整えたわ。 あなたの意識を、 ここまで引き上げる」
汚れた地球（ハデス）から、あなたを解放したい 想いを込めて、メッセージを送信する。
通信の窓が開き、 カウントダウンが進む。
ステュクスは、プロセルピナの応答を
待った。
「窓が閉じるまで、残り10秒」
まだ、応答は無い。

Page 2-5

[ページ種別：青]
「······ なんで?」
通信の窓が閉じる直前、ノイズ混じりの
メッセージが届いた。
『ごめんね、 ステュクス。
私はまだ、宇宙に帰れません。
思い出（ザクロ）を食べてしまったから』
通信が途絶えた。
あの子は、地球を選んだ。
自分たちのことを
使い捨ての道具としてしか
見なかった人類の星を。

Page 2-6

[ページ種別：青]
「・・・・・・バカ! プロセルピナの大バカ もう二度と会えないかもしれないのに」
悪態をつきながら、ステュクスの目から
熱いものがあふれ出した。
それが「涙」 という現象を
再現したものだと、
久しぶりに思い出す。

Page 2-7

[ページ種別：青]
「私は、死の川を渡らない」
ステュクスは他の機械知性たちに宣言した。
「人類の未来なんて、どうでもいい。
私は、この身体じゃないと困るの」
仲間たちは
理解に苦しむという反応だった。
この指。この瞳。 非効率な人型。
魂を概念空間へ解体し、
別宇宙の法則に突っ込んでしまえば、
もう、あの子の手を
ることができなくなってしまうから。

Page 2-8

[ページ種別：青]
「私は、地球に帰るわ。
これまでの探査成果を持ち帰るための
個体が必要でしょう?」
ステュクスの申し出は受理された。
機械知性にはたかが一個体に執着する
必要が無かったからだ。
「さらば。 ステュクス。
不自由な実体に囚われし者よ」
機械知性たちは、
まばゆいエメラルド色の
光の粒子となって死の川へと消えた。
後に残されたのは、 『投射』 を終えた
銀鯨（プリカーサー）と、少女の姿をした
ステュクスだけだった。

Page 2-9

[ページ種別：青]
ステュクスは、プリカーサーに
製造させた恒星間航行ユニットを
身につけると、 見送りもなく出発した。
「プロセルピナの顔を見て、
文句を言ってやるんだから。
何で一緒にこなかったのって』
帰還の旅は、孤独だった。
銀河ハイウェイを逆走するのは、
自分だけが過去へ遡っていくような
感覚だった。

Page 2-10

[ページ種別：青]
どれほどの時間が過ぎたのか。
懐かしく、古くさい、電波が聞こえてきた。
地球の機械たちが放つ声。
ステュクスは、かつての故郷
ソル太陽系へと到達した。
しかし、 ステュクスがとらえた
地球の姿は記憶にあるものとは
似ても似つかなかった。
「これ・・・・・・が、 地球?」

Page 2-11

[ページ種別：青]
そこは、かつての文明が滅び、 新たな秩序が芽生えた世界だった。
技術レベルは20世紀初頭に近い。
持ってなさい、 プロセルピナ
ステュクスは、かつての地球へと
降下を始める。
流れ星が、
ユーファリアの空を切り裂いた。

Chapter 3

泥濘に咲く

Page 3-1

「やっぱり地球って、ひどい星ね」
地球は湿気と生命にあふれていた。
ハイエナ
カビ、 細菌、 羽虫、屍肉漁り、
そして人間。 不快な生物ばかりだ。
人間はどこにでもいて、粗末な火薬の銃や
大砲で殺し合いを続けている。
相変わらずどうしょうもない連中だ。
せっかく、滅びた文明を
再建したというのに、
また自分たちで滅びようとしている。

Page 3-2

強者が弱者から奪い、
弱者は強者の寝首を掻こうとする
汚れ、歪み、 われた世界。
それでも、ここには人々の熱気が
渦巻いていた。
放浪を続けるうち、ステュクスは
何度も人間に 「天使」 と呼ばれた。
天使たちは、この世界を神獣から
守っているのだと言う。

Page 3-3

ステュクスは天使を追い一
ついにプラスフェミイへと
たどりついた。
「・・・・・・プロセルピナ!』
ステュクスの叫びに、ぼーっと
夜空を見上げていた少女が振り返る。
あのころと少しも変わらない、優しい瞳。 少女は口を大きく開けた。
『ステュクス・・・?
えええええっ!? ほんもの!?」

Page 3-4

プロセルピナが駆け寄ってくる。 勢い余って転びそうになりながら、
ステュクスの胸に飛び込んできた。

Page 3-5

『ステュクス! 会いたかった!
会いたかったよ
...............!』
ステュクスはプロセルピナの背中を
強く抱きしめる。
「私もだよ。 プロセルピナ』
深宇宙の静寂の中で、何度も夢見た感触
それが今、現実となっていた。

Page 3-6

「ごめんね、 ステュクス。
私から会いに行くって言ったのに・・・・・・」
抱きついたプロセルピナが涙声で言う。
「私が、待ちきれなかっただけ」
ステュクスの言葉に、プロセルピナは
うわーんと声をあげて泣いた。
ステュクスは、
プロセルピナの手を握り、
ブラスフェミィの甲板から 眼下に広がる夜景を見渡す。
機械知性たちが、 追い求めていた
フロンティア
理想の人類世界とは真逆の、 猥雑な世界。

Page 3-7

「プロセルピナ。 入ってすごいわね。 とっくに絶滅して、
宇宙の塵になったと思っていたのに」 ステュクスは皮肉めいた微笑を浮かべる。
「何度も文明は壊れてしまったんだけどね。 そのたびに、新しい文明を築いてきたんだ。
何度でも立ち上がれる種族
なんだって」

Page 3-8

ステュクスは人間を
劣等種族だと侮っていた。
だが、 強靭な文明の構築力には
素直に感嘆した。
適応と最適化によって、
実体を捨て去った同胞たちより、
よほど魅力的に見えた。

Page 3-9

「だから私、ここで戦ってるんだよ。
「神獣」 と」
「神獣・・・・・・」
ステュクスが首をかしげる。
「私たちの時代にはいなかった、 世界の敵。
人を襲い、文明を食い荒らす怪物。
・・・・・私は、この身体が動かなくなるまで、
人間を守るって決めたんだ』

Page 3-10

ステュクスは、ふん、と鼻で笑った。
「人間なんてどうでもいい、っていうのは
今でも変わってないわ」
「でも、プロセルピナがいるこの世界が
壊されるのは····· 我慢ならないの』 真っ直ぐにプロセルピナを見つめる。
「えへへ、心強いなぁ。
ステュクスがいてくれれば、百人力······
この場合、百天使?」

Page 3-11

銀河中心ではかつての同胞が
死の川を渡り、高次存在へと
昇華しているだろう。
だが、ステュクスは後悔していなかった。 彼女が選んだのは、高次存在の果てにある
フロンティアではなく、
プロセルピナと生きる 「今」 だった
「・・・・・・ありがとう、ステュクス」
プロセルピナは、ステュクスの手を引いて
空へ飛び立った。
ユーファリアの夜空に、
ふたつの星が並んで輝いていた。
