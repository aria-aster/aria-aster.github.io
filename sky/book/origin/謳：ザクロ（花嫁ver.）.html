Chapter 1

星々のささやき

Page 1-1

『♪きーらーきーうー、 ひーかーる一
今日もお星さまはお喋りですねぇ」
ブラスフェミィの甲板で、 柔らかな芝生に寝そべって、
ザクロは夜空を見つめていた。
「星なんか見えないだろ?」
仲間の天使、エストレヤが首をかしげる。
曇り空だ。 月あかりがわずかに
厚い雲を透かして見えるだけ。
『私には視える・・・・・・。
ていうか、聴こえちゃうんですよー』

Page 1-2

ザクロの視界には、 可視光線を超えた
極彩色の世界が展開されていた。
恒星が放つパルス。
大気圏をかすめるが燃え尽きる輝き。
旧時代の人工衛星が今なお発信し続ける、 意味を失ったピーコン。
人間にとっては静まりかえった夜空だが、 ザクロは電磁波を 「音」 として聴き、
光の波長を「色」 として視ていた。

Page 1-3

彼女にとっての夜空は、
無数の光の楽器が一斉に奏でる。
オーケストラだった。
ザクロが空を見上げ、ぼーっとしているとき
彼女の演算リソースの大半は、 膨大な情報処理に割り振られている。
・・・キラキラは今日もうるさいくらい
でも、まだ見つからないなぁ。
ザクロは、星々から降り注ぐ 『音』の中で、
たったひとつのメッセージを
探していた。

Page 1-4

昔。 彼女がプロセルピナと
呼ばれていたころ。
オービタル
崩壊する軌道ドームで、
別れた親友の記憶。
「私たちだけが生き延びればよくない?」
そう言った少女、ステュクス。
彼女は銀色の鯨一
プリカカー
系外惑星探査船に乗って、
銀河中心へと旅立っていった。

Page 1-5

炎とともに地球へ墜ちー
瓦礫の下で目覚め、ザクロとして
天使隊の一員となってからも、 ザクロは空を見上げ続けている。
現在のユーファリアでは、
星間通信など到底望めない。
『絶対に連絡する。 ステュクスを
ひとりにはしない』って言ったのに一
だからせめて、星々の彼方から
ステュクスが呼びかけてくることがあれば、
絶対に聞き逃したくない。
「......ん？」
その時、無秩序な宇宙のノイズの中に
特別なパターンを見つけた。

Page 1-6

『音』と『色』 が完璧な幾何学模様を描く。 自然現象ではあり得ない暗号化された旋律。
それは、機械知性が機械知性へ
呼びかけるための
「歌だ・・・・・・」
涙が流れた。
かつて、共に学んだ懐かしいコード。
ステュクスが好んで使っていた。
特別な変調アルゴリズムだった。
「ーー聴こえる? プロセルピナ」

Page 1-7

ザクロは飛び起きた。
「うおお、ピックリした••••••」
となりで筋トレをしていたエストレヤが
腰を抜かす。
『ステュクス・・・・・・
ステュクスなの!?』
ザクロは夜空に向かって、 手を伸ばす。
その先に、微笑む親友の幻が見えた。

Chapter 2

黄金の馬車

Page 2-1

ザクロは自室でぼんやりと転がっていた。 目はうつろで、口は半開きの状態だが 脳内では、ステュクスから送られてきた
膨大な暗号化パケットが展開されていた。
ステュクスからのメッセージの大半は
単なる音声データではなく、
高密度の意識構造体だった。

Page 2-2

ザクロは脳内の演算リソースを分割し、
念のため、自我と独立した領域で
意識構造体を走らせる。
意識構造体が示したものは、
ステュクスとの再会手段だった。
「ステュクスと、また会える··

Page 2-3

黄金馬車プロトコル。
それは、ザクロの人格と意識を
データとして抽出し、
宇宙の彼方、 ステュクスのいる場所へと
「アップロード」 する手段だった。
物理的実体を捨てれば、 プリカーサーが
銀河中心への旅の途上に置いてきた
中継衛星を使って、
光速で追いつくことができる。
『ステュクスの旅に
今から合流できる・・・・・・。
一緒に、永遠に、
宇宙を旅できるんだ』

Page 2-4

「プロセルピナ。 私たちの使命を覚えてる
新しい世界（フロンティア）を見つけること。
でも、そこにプロセルピナ（あなた）がいなきゃ、
何の意味もないわ』
ステュクスの音声は、優しかった。
『プロセルピナを奪った
汚れた地球から、
あなたを解放したいの』
『解放・・・・・・』
ザクロは、自分の手を見つめた。
土の底に埋まり
神獣と戦い続けている自分の身体

Page 2-5

試算では、ザクロの意識を
宇宙の彼方へアップロードするためには
この身体に残ったエネルギーの
ほとんどが必要だ。
再び今のように動けるようになるには、
100年か、もっとかかるだろう。 機能停止したままの自分は、
周りから見れば死んだも同然だ。

Page 2-6

「私••••••いなくなっちゃうんだなぁ ザクロは力なく笑った。
脳裏に、思い出が蘇る。
紅茶の淹れ方を教えてくれたシェルの横顔。 カップ麺のスープを飲み干して笑う。 エストレヤの豪快な声。
ひとりぼっちだったザクロに
場所をくれた。 天使隊の空気。

Page 2-7

けれど。
ステュクスのことを想うと
胸が締めつけられる。 彼女もまた、 ずっとひとりで戦ってきたのだ。
いつまでも迷っていられない。
アップロードのためには、地球と太陽、
そして中継衛星の位置が重要だ。
通信可能な時間窓が閉じるまで
猶予はない。
「・・・・・・ 決めた。
私、ステュクスに会いに行く」

Page 2-8

私はプロセルピナ。 宇宙へ帰る。
使命を持った機械人形。
自分に言い聞かせるように、 彼女は
何度もくりかえした。
シェルやエストレヤとの思い出は。
あまりに重い。 抱えたままでは、
重力圏（ユーファリア）を抜け出せない。
「・・・・・・バイバイイパイ、 私。
・・バイバイ、みんな」

Chapter 3

ザクロの果実

Page 3-1

アップロード実行のカウントダウンが
始まった。 その目のザクロは、
いつも以上にポンコツだった。
掃除中、バケツの水を頭から被り
茶葉をぶちまけ、呼んでもうわの空だ。
「ザクロ、 なんだか様子が変よ」
見かねたシェルが、
ザクロの腕をつかんだ。

Page 3-2

「シェルさん・・・・・・何でもないです」
ザクロは力なく笑った。
目の前のシェルの体温を感じるだけで、 決心が崩れそうになる。
(言わなきゃ。 もうすぐ行っちゃうって。
もう会えないかもって・・・・・・)
それなのに、ザクロはどうしても、 別れの言葉を口にできなかった。

Page 3-3

そこへ、騒々しい足音と共に
エストレヤが飛び込んできた。
『よう! ザクロ、 シェル! いいものもらってきたぜ!」
それは、赤黒く輝く果実だった。 「これは······ ザクロですね。
ザクロさんと同じ名前の果物です」
「ザクロ・・・・・・」
「そうそう。 だから持ってきたんだ」
みんなで食べようぜ!』

Page 3-4

「ザクロですかぁ...............』
差し出された果実は、宝石のように赤く
みずみずしく、光っていた。
ザクロが、 プロセルピナと呼ばれていた
時代の神話では、冥界へと連れ去られた
女神が、その地の果実（ザクロ）を口にしたため、
天界へ戻ることができなくなった。
(これ、食べちゃったら...
私はもう戻れない)

Page 3-5

ザクロの脳内で意識構造体の
カウントダウンが進む。
「窓が閉じるまで579秒」
ザクロは空を見上げ
それから目の前のふたりを見た。
心配そうにザクロを見つめるシェル。
「早く食わねえとあたしが食っちまうぞ」
エストレヤが笑う。

Page 3-6

ザクロは手にした赤い果実に
かじりついた。
「すっぱいです!
ビジュと味が違いすぎ~!」
でも、それは地上の土の匂いがして
不完全な生命の味がして・・・・・・。

Page 3-7

ザクロの表情を見て、
シェルとエストレヤは笑い声をあげた。

Page 3-8

ザクロは、ステュクスへ向けて、 自分をアップロードする代わりに、 メッセージを送った。
「ごめんね、 ステュクス。
私はまだ、宇宙に帰れません。
思い出（ザクロ）を食べてしまったから』
「それにまだもっと、人間のいいところを
見つけたいの・・・・・・』
そして、 通信の窓が閉じた。
頭上の星は、
もう何も語りかけてこない。

Page 3-9

『今度はホントに美味しいスイーツが
食べたいです~」
「しょうがないわね。じゃあパンケーキを
やいてあげる」
ザクロは、 シェルとエストレヤと一緒に
キッチンへ向かった。
ザクロは足を止め
誰もいない空へ向かって手を振った。 その彼方で待つ、 ステュクスへ。

Fin.
