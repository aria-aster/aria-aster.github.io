Chapter 1

ノーライス・ノーライフ

Page 1-1

師走はブリが旨い。
魚に師と書き師と読むほど旬である。
こんな季節はブリッジに限る。
ブリッジをすると、
筋肉から脳に血液が流れ込み、
スシエルはほんの少し賢くなる。
「ノーライス! ノースゥシィ!」
スシエルが叫んだ。
米がないことを思いだしたのだ。
今年、帝国は歴史的な米不足だった。
補給物資の米が尽き、 握るシャリがない。
7032 いったいどうすりゃいいんだい!

Page 1-2

「お寿司がなければ
パンを食べればいいじゃない。
なんならケーキも用意するわよ!』
スシエルの腹筋をベンチ代わりに尻をのせ、
パンの天使エクスカリパンが
しゃらくさいことを言ってきた。
「ヤーッ!!」
スシエルは自慢の腹直筋で跳ね起き
腹の上のエクスカリパンを、
パーンと天井に叩きつける!

Page 1-3

スシエルの脳みそは筋肉でできており、
筋肉は限界をこえたときに成長する。
ブリッジで痛めつけられた脳に、
過去の記憶がフラッシュバックした!
「そうだ、あの島、行こう」

Page 1-4

かつて漂流した無人島。
そこには、無限に米が湧き出る
「伝説の炊飯壺（ジャー ）」 が埋まっていた。
「待ってろ、 炊飯ジャー!」
これで米（シャリ ）問題は解決だ!
天井に突き刺さったままの
エクスカリパンを放置して、
スシエルは無人島目指して飛び出した。

Page 1-5

吹き荒ぶ風、叩きつける雨。
閃く雷。 迫る波濤（はとう）。
嵐を突っ切り。 スシエルは飛ぶ。
星空の下、懐かしの無人島が見えてきた。
無意味にスーパーヒーロー着地をキメる。
浜辺はあのときと変わらず――いや、
あのときにはなかった難破船が増えている。
真新しい船だ。
この船も、 神獣の餌食になったのだろうか?

Page 1-6

「まあいっか」
そんなことより、無限の炊飯ジャーだ。
さっさと見つけて持ち帰らねば。
あっちだったか、 そっちだったか。
それともこっちか・・・・・・。
「どっちなんだいっ!」
もちろん、返事はない。

Page 1-7

「時すでにおすしい・・・・・・?」
まさか、他の漂流者か誰かが
持って帰っちまったなんて、
そんなことーー
「はぺぷっ!」
スシエルは何かに足を取られて
顔から浜辺に突っ込んだ。
起き上がると、砂の上に伸びている
謎のロープが見つかった。

Page 1-8

ロープを引くと、
グイッと引き返される手応えがある。
スシエルはニヤリと笑った。
「ほう、綱引きかい?」
相手が何者かは知らないが、 筋肉勝負で
スシエルが退く訳にはいかない。
「パワーッ!」
ぐっと足を踏ん張り、腰を溜め、
ヤーッ!と力任せに引っぱった。
ロープの先にはいったい何が?
スシエルの運命やいかに!

Chapter 2

百少年漂流記

Page 2-1

「ヤーーーッ!!
スシエルが背筋力全開でロープを
引っぱるとーー
「うわあああ!」
悲鳴と共に、ロープを握る子供たちが
すっ飛んできた。 その数は、
いち、に、たくさん……おそらく百人。

Page 2-2

こりゃピっくりポン!
スシエルはシャリを握るように優しく
しっかり子供たちをキャッチする。
さらに何かが降ってくる。
「こいつはー!」

Page 2-3

「会いたかったぜ! 私の炊飯ジャー!
ロープの先についた炊飯ジャーを
スシエルはキャッチ&キーッス!
「かえ、 して•••••• ごはん······」
「お腹減ったの・・・・・・」
放り投げられた子供たちが、
ゾンビのように近づいてくる。
ガリガリにやつれ、 まるで干物だ。
「おっと悪い。
すぐに、ご馳走用意すっからな」

Page 2-4

「食いねぇ食いねぇ! 寿司食いねぇ!」
スシエルは目にも止まらぬ速さで
その辺の海藻と魚 (現地調達)をさばき、
ジャーの米で寿司を握った。
「ヘイお待ちッ!」
ガリガリの子供たちの口に、
スシエルは寿司をねじ込む!
ねじ込む!ねじ込む! ガリもねじ込む!
「寿司は完全食（パーフェクトフード）! 食えば元気になる!
ならなきゃおかしい!」

Page 2-5

『美味しい! これが・・・・・・ スゥシィ ?」
カッと覚醒した子供たちが、
もっともっとと寿司へと手を伸ばす。
「うまい、うますぎる!」
「スシエルありがとう!」
子供たちの笑顔にスシエルは胸が熱くなる。
これが板前の喜びだ。

Page 2-6

「カッパッパ!
まだまだ握るぞ、どんどん食え!」
スシエルは満足げに笑って、
無限炊飯ジャーの中を覗きこんだ。
「おっと、もうなくなっちまったか?」
あまり容量が大きくないのが、
この炊飯ジャー唯一の欠点だ。

Page 2-7

だがしかし! 無限に米が湧く炊飯ジャーに
容量など関係ないのである!
「はれえ······?」
気の抜けた声に振り返れば、
子供たちがへなへなと座りこんでいた。
「寿司パワー切れか! 待ってろ!」
新たにチャージした米で寿司を握ると、
スシエルはへたった子供に振る舞った。
「スシエル、 ありがとう!」
そして元気になった子供は満面の笑みで
再び駆け出したのだが、
すぐにばったり倒れてしまう。

Page 2-8

「何でなんだい!」
スシエルは叫んだ。
寿司を食わせても食わせても、
子供たちが元気になるのは一瞬で
すぐにへたり込んでしまう。
それどころか食わせれば食わせるほど
弱っていくようだ。
寿司を食べて弱るなんてあり得ない。
何か別の原因があるはずだ。
何か―

Page 2-9

スシエルは試しに
自分が握った寿司を食べてみた。
パーフェクトに美味い。
パワーは減るどころかモリモリ湧いて。
1000パーセント寿司パワーでムキムキだ。
だったら何でなんだいっ、と頭を抱える
スシエルの目の前で、空の炊飯ジャーに
米がチャージされたそのときだった。
「ムキッ!? パワーが……減った?」
スシエルはハッと息を呑んだ。

Page 2-10

「おい、 炊飯ジャー!
キミがみんなの生命力（パワー）を
吸い取っているのかいっ!?」
心なしか。 今までよりもずっとつやが良く
ふっくら炊き上がった極上の米が
炊飯ジャーの中で輝いている。
スシエルはゴクリと喉を鳴らした。
とにかくかっ食らいたくなるような、
美味そうな白飯だ。

Page 2-11

「スシエル もっと食べたいよ。
お腹減ったぁ・・・・・・ スシエル・・・・・・』
げっそりとした子供が
炊きたてのご飯に手を伸ばす。
スシエルは炊飯ジャーを持ち上げた。
「こいつは罠だ!」
美味そうなご飯で人をおびき寄せ
人間の生命力を吸い取る
ヤベー、ブツだ!

Page 2-12

米がなくては寿司は握れない。
だが、米を炊けば
子供たちはますます飢える。
「いったい全体、 どうすりゃいいんだい!」
ーー頑張れスシエル、 負けるなスシエル!
子供たちの運命は
お前の頭の冴えに懸かっている!

Chapter 3

アークエンジェル

Page 3-1

生命力を奪って米を炊く炊飯ジャー
飢える子供たち
To be
握るのかい!
or not to be
握らぬのかい!
that is the question
どっちなんだい!
「なあに、簡単なこと!
板前にできることは、
寿司を握ることだけだ!」

Page 3-2

いいぜ。
炊飯ジャー（おまえ）が生命力（パワー）を吸い取るってんなら、
まずは、 それ以上の生命力を
子供たちにぶち込んで（プレゼントして）やる!!

Page 3-3

釣る! さばく! 握る! 食わす!
釣る! さばく! 握る! 食わす!
スシエルの生命力を吸って炊き上がった米で
握った寿司は、子供たちの生命力を
満ち満ちにした。
まだまだぁ!
子供たち、寿司を食って
マッチョになれ!
子供たちと楽しく仲良く
スクワットを開始!

Page 3-4

握る! 食わす! スクワット！
握る! 食わす! スクワット！
尽きることのない寿司飯（シャリ）、 止まることのない握りの速さ。
スシエルの手は、
音を置き去りにした。

Page 3-5

スシエルは寿司を握ることしかできない。
だが、 寿司を握ることならば
誰にも負けない。
負けるはずがない!
大天使が握る寿司の前では、 エネルギー保存則など戯言である。

Page 3-6

炊飯ジャーが奪った生命力を、
スシエルの寿司が与える生命力が
上回っていく。
寿司とスクワットにより
子供たちのガリガリボディは、
みるみる強靭なマッチョボディへ
変わっていった。

Page 3-7

「パワー!」
スシエルと子供たち百人の声が
無人島に響き渡った。
不意に、うめき声のような地鳴りが響く。
無限炊飯ジャーがガクガクと震え
やがて夜空高く米を噴き上げた。
「とうとう出やがったな!?」
地面を割り、巨大な怪物が現れた。
そいつはチョウチンアンコウのように、
炊飯ジャーを触手の先にブラさげている。
「こいつが本体か!」

Page 3-8

白米をエサにして、漂着した人の
生命力を奪っていたのだろうが・・・・・・
それもここで終わりだ!
「やっちまえ子供たちぃ!」
子供たち百人が、
一斉にパンチを怪物に叩き込む!
子供とはいえ、 スシエルの鍛えた
鬼マッチョ。
怪物は一瞬で、ボコボコだ。
「とどめは任せな!」
スシエルはフルパワーで寿司を握る。
寿司に限らず物質は、
極限まで圧縮されると
核融合状態となりーー

Page 3-9

「これでも食らえ! 寿司ざんまい!!」
怪物の口の中で、投げ込まれた寿司が
音と共に爆裂する。

Page 3-10

怪物は爆発四散!
子供たちが歓声をあげる。
そう、
高度に熟達した板前の握った寿司は
爆弾にもなるのである!

Page 3-11

「やっぱり寿司は最強だぜ・・・・・・」
勝利を喜びニンッと笑んだスシエルが
顔を上げると、遠くに船影が見えた。
スシエルは再びぎゅぎゅっと寿司を握る
「もういっちょ! 寿司たあまやぁ!」
真上に投げ上げた寿司がパァンと弾け
「米」のかたちに広がる。
花火寿司である。
船がこちらへと舳先を向けるまで、
何発もの花火寿司が
夜空に大輪の 『米』 を咲かせたのだった。

Page 3-12

「ありがとう。 スシエル!」
「スシエルのお寿司、 忘れないよ!」
到着した救助船に乗り込み、
子供たちはスシエルに手を振った。
救助にきた船員たちは子供たちが
軒並みマッチョになっていることに
首をかしげながらも、
皆が無事であることを喜んだ。
「元気でなー! 筋トレ忘れんなよ!」
子供たちを乗せた船が小さくなっていく。
さてと・・・・・・。

Page 3-13

足を生やし、 カサカサと逃げようとした
無限炊飯ジャーを
スシエルはガシッと掴む。
「逃がさないぜ相棒・・・・・
ずっと、寿司を握り続けよう。
永遠にな」
スシエルは満面の笑みで
カタカタ震える炊飯ジャーに頬ずりをした。

Page 3-14

東の空が黄金に輝き、 太陽が顔を出す。
新しい年を賀する初日の出だ。
「カッパッパ! こいつは縁起がいいな!」
スシエルは豪快に笑い。
元旦の空へと飛び立った。
ヤーッ!
この年、 ボディビル子供部門は
例年にない豊作の年となるのだが・・・・・・。
それはまた別の話。
