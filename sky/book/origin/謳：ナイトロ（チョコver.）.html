チョコをお届け

Page 1-1

「すいません、 みすずさん。
せっかくのお休みなのに、
こんなお願いをしちゃって・・・・・・』
2月のキンと冷えた。
チョコレート工場で働くネロが、
白い息を吐きながら眉を下げた。

Page 1-2

あたしは工場からただよう 甘い香りを吸い込みながら、 どんと胸を叩いてみせる。
「問題ナッシングだぜ!
運ぶのはあたしの十八番（オハコ）だし、
頼ってくれて嬉しいよ」

Page 1-3

ネロは以前、軍の研究所から
助けだした子供たちのひとりだ。
今はこうして、平和にチョコを作ってる。
だが、 その平和な工場が
神獣騒ぎのせいで操業停止。
ようやくラインが動いたと思ったら······。
今度は薄情な契約ドライバーが トンズラこいたときたもんだ。
そこであたしに、 お鉢が回ってきた。

Page 1-4

依頼はこうだ。 明日の朝イチまでに、
チョコをお店に届ける。 逃せば
バレンタインっていう最大の商機を失う
「任せな、 5分で届けてやるよ!」
キレイなチョコを満載したトラックで、 あたしは意気揚々と出発した。
道路を流していると
前方の路肩に手をあげる影が見えた。
小柄な女性がヒッチハイクをしている

Page 1-5

速度を落とそうとした、 そのときだ。
後ろから別のトラックが
猛スピードで迫ってくるのが見えた。
路肩にはみ出し、
強引に追い越しをかけてきやがる。
「あぶねえ! 見えてないのかよ!」
あたしはとっさに急ブレーキを踏み、
トラックのケツを振って、
暴走車に軽くキスをしてやった。

Page 1-6

暴走車は土煙と
クラクションの断末魔をのこして 森の茂みへと突っ込んでいく。
悪いが、人命第一なんでね。
あたしは窓を開けて声をかける。
「へい、 おじょーちゃん!
どこまで行きたいの?』

Page 1-7

「愛する人の所までさ」
振り返った顔を見て、
あたしは目を丸くした。
ハデな服に金髪のツラ。
それはお嬢ちゃんじゃなくて、
夢見る目をしたばあさんだった。
話を聞くと、山の上のお屋敷に
行きたいのだという。

Page 1-8

「ごめん、ばあさん。
あたしの行く先は、山の向こう側なんだ」
乗せていけないのは心苦しいが。
ネロとの約束を破るわけにはいかない。
だが、ばあさんは不敵に笑った。
「山向こうに行きたいなら、
地元民しか知らない
「地獄の裏道（デスロード）」を
通ればすぐよ』

Page 1-9

「マジか?(デスロード?)』
「その途中で、 お屋敷のそばを通るんだ
乗せてくれたら案内するよ」
裏道を使えば、
大幅なショートカットになる。
あたしはニッと笑って親指を立てた。
『オッケー、 乗りな!
デートに遅れちゃ野暮だからね!」

Page 2-1

「若いころ、 死ぬほど惚れた男がいてね」

身分違いの恋、親の猛反対。

Chapter 3

ラブをお届け

Page 3-1

獣道は大きな道路につながっていた。
その先にあらわれたのは、大きなお屋敷と、 門の前で待つ、老紳士の姿だった。
ばあさんがトラックから降りると、
老紳士が駆け寄ってきた。
ふたりは言葉もなく、
ただ強く抱き合う。

Page 3-2

数十年分の空白が、
月明かりの下で埋まっていく。
チョコよりもずっと甘い光景だ。
あたしが鼻をすすると、
ばあさんは少女のような顔で振り返る。
「連れてきてくれてありがとう、
イカした運転手さん」
「いいってことよ」
その笑顔に胸がいっぱいになる。
だが、ここで問題発生だ。
プスン、 と情けない音を立てて
チョコ工場のトラックが煙を吐いた。

Page 3-3

さすがに無理させすぎたか、ご臨終だ。
「さて、どうしたもんか••••••」
頭を抱えるあたしに、
ばあさんがニヤリと笑みを見せる。
「それなら大丈夫』
ばあさんが向かった先
屋敷の駐車場にあるものを見て、
あたしは我が目を疑った。

Page 3-4

闇夜に煌めくネオン! 極彩色のペイント! 俺の如きマフラー!
そこに鎮座していたのは、
伝説級の超ド派手なデコトラだった。

Page 3-5

「これ、じいさんの車?』
「いいや。 ハニーのじゃ」
このばあさん。
昔は相当ヤンチャしてたらしい。
「アタシの愛車を貸してあげる。
そこらのトラックより速いよ!」

Page 3-6

ボコボコのトラックから、
デコトラに荷物をつめかえる。
エンジンを掛ければ、腹の底に響く爆音。
最高だ。
「ありがとよ、お幸せに!」
ふたりに見送られて屋敷を出発する。
ばあさんが言っていた通り、
とんでもない馬力だ!
これなら余裕で間に合うぜ!

Page 3-7

約束の時間ギリギリ。
極彩色のデコトラが店の前に滑り込む。
『本当にありがとうございました。 みすずさん!』
店で借りた電話の向こうで、
ネロの弾んだ声が聞こえる。
誰かの想いを乗せて走るってのは
運び屋の仕事の醍醐味だ。

Page 3-8

夜空を見上げる。
星よりも眩しいデコトラの電飾が
アスファルトを照らしていた。
『礼なんていいさ。
来年も気が向いたら、運んでやるよ

あたしは再びアクセルを踏み込んだ。
