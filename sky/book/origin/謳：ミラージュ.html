Section:

謳：ミラージュ

Chapter 1

身から出た錆

Page 1-1

暖かな昼下がり。 帝都のメインストリートで
開催されるマーケットの片隅から
賑やかな音楽と笑い声が聞こえてくる。
楽人音楽家や大道芸人たちが、
自慢の技術を披露しているのだ。

Page 1-2

「さあ、 鳩が出ますよ！」
手品師のシェリルが、
空っぽの帽子を見せ
ステッキで帽子を叩く。
すると、中身がなかったはずの帽子から、
白い鳩が何羽も飛び立っていった。
観客の拍手と歓声が巻き起こる。
「どうもどうも!」
頭を下げ、 シェリルが帽子を差しだすと
観客が笑顔でチップを投げ入れた。
「ありがとう! みんないいことあるよ!」

Page 1-3

「♪〜。 今日も売り上げは上々かな」
あちこちで店をたたみ始め、がらんとした
マーケットの隅で、シェリルは
稼ぎのチップを数えていた。
「さっすが。 天才は違うね」
相棒のニッキーがシェリルに声をかける。

Page 1-4

「そんなんじゃないって。 で、 そっちは?」
シェリルがたずねると、 ニッキーは
トランプカードのように財布や札入れを
広げて見せた。
シェリルとニッキーはコンビだ。
シェリルの芸に夢中になっている不注意な
客のポケットからニッキーが 「お恵み」を
いただく。 それが彼女たちの日課だった。

page 1-5

「近頃はずっと、 シェリルの方が稼ぎも
多いんだし、もうピンでやったら?」
ニッキーが言うと、シェリルは
ロをとがらせた。
「そんなのいやだ!
私たちずっと友達でしょ！？」
捨て子だったシェリルを救ったのは
ニッキーだった。 ニッキーの優しさと、
スリの技術のおかげで、シェリルは今まで
生き延びてこられたのだ。
「さぁ山分け、 山分け!」
つとめて明るくシェリルが言うと、
ニッキーはそれ以上、何も言わなかった。

Page 1-6

――そんなある日のこと。
ニッキーが下手をうった。

Page 1-7

「知らないって言ってるだろ！」
ニッキーの類は腫れ、 警官によって地面に
押さえつけられている。 その周りを野次馬が
取り巻いていた。
「お前が盗んだんだろう?
言わなければもっと痛い目にあうぞ」
身なりの良い貴族がつま先でニッキーの
額をこづいた。
「どいてどいてー!」
大荷物を抱えた少女が、 人混みにぶつかり、
盛大にスッ転ぶ。 荷物の中から飛び出た
小さなハツカネズミがあたりを駆け回った。

Page 1-8

悲鳴をあげる野次馬たち。
転んだのはもちろんシェリル。
ハツカネズミは手品の小道具だ。
周りの注意がネズミに向いた瞬間、
シェリルは、 ニッキーの懐から
貴族の財布を抜き取った。
「何をやっている! 貴様も逮捕するぞ!」
警棒を振り上げる警官に、 シェリルは
ウインクした。

Page 1-9

「おまわりさん、いいところに。
さっきそこで財布を拾ったんですけど......」
その財布を見て、 貴族は大声をあげた。
「そ、それは私の財布！」
「なぜそこに・・・
確かにこいつにスラれたんだ!」
「えー、 それって勘違いじゃないですかー。
それでこの仕打ちってひどくないですか？」
シェリルの言葉に貴族は顔を真っ赤にする。
「ぐ......」

Page 1-10

「じゃ、 お巡りさん、 私はこれで......」
立ち去ろうとするシェリルの手を警官が
掴む。
「貴様も共犯なんだろ？」
「はぁ！？」
シェリルはシラを切るが、内心で
冷や汗をかいた。
どこまでバレてる？

Page 1-11

「あー!
「そいつは関係ない!」
ニッキーが必死の形相で食い下がる。
「続きは留置所で聞かせてもらおう。
こいつらを連れていけ！」
シェリルを警官たちが取り囲んだ。
「あー！
いいのかなそんなことしてぇ！」
マーケットの手品ショーで鍛えた大声を
出すと、さすがに警官たちもひるんだ。
「私が誰だか知らないの？
国民的人気アイドルマジシャンの
シェリルちゃんにそんなことして、
暴動おこってもしらないよ？」

Page 1-12

「国民的人気アイドルだとぉ？
何を言っているんだ貴様は?」
警官が苦虫をかみつぷした顔をする。
「とっとと連行しろ」
「まあ待ちたまえ」
助け船を出したのは、意外にも先ほどまで
激怒していた貴族だった。
「そのような有名人とは知らず失礼した」
「え?いや分かってくだされば結構……」
不穏なものを感じ、 逃げようとする
シェリルを貴族が引き留めた。

Page 1-13

「お待ちください。 それほどの方なら
どうか、晩餐会でマジックを披露しては
いただけませんかな？」
「なんですと！？」
事態に困惑していた警官り、
ようやく貴族の意図が飲み込めた。
つまりは、逃げられない場所で
こいつらに恥をかかせてやろう
ということなのだ。
「まったく趣味が悪い……」

Page 1-14

「い、いいでしょう。 やってみせますよ。
史上最高のマジックショーを！」
貴族の悪意を知ってか知らずか、シェリルは
依頼を引きうけてしまうのであった。

Page 1-15

解放されたシェリルとニッキーは、
川を眺めながら呆然としている。
「なぁ、あんなこと言って本当に大丈夫?
国民的超人気マジシャンとか・・・・・・。
もし嘘がばれたら、どうするんだ?」
「あ、うん。 そうだよね。
はあ······ どうすりゃいいんだよぉ」
身から出た錆とはいえ、
シェリルの心はとてつもないプレッシャーで
押しつぶされそうになっていた・・・・

Chapter 2

藁にもすがる

Page 2-1

「鳩を出してもなあ……」
目の肥えた貴族たちを前に、
果たして シェリルには、何ができるのだろうか。
晩餐会が翌日に迫り、シェリルは
絶望していた。

Page 2-2

「お困りのようですね?」
シェリルが川面を眺めながら遠い目を
していると白い帽子をかぶった男が
声をかけてきた。
「え？誰？」
「先日、 助けていただいた鳩です」
「は？何？」
「ふふっ、 冗談ですよ」

Page 2-3

「まずはコーヒーでもいかがですか?」
返事も聞かず、男はポットのコーヒーを
カップに注いだ。
「コーヒーを美味しく淹れるコツは、
まずは経験。 それ以上に愛情です」
正直コーヒーなど飲む気分ではなかったが、
仕方なく一口だけ飲んでみることにした。
「！」
意外と、まともな味がした。
コーヒーを味わっていると
「クルッポー クルッポー！」
帽子男が鳩の鳴き真似をやり出したので、
シェリルはコーヒーを吹きだしてしまった。

Page 2-4

やべーやつに絡まれてしまった。
一刻も早くこの場を離れなければ……。
カップを返して早く立ち去ろう。
「コーヒーありがとうございました。
それじゃ、 私はこれで......」
シェリルはカップを差しだす。
「コーヒー?なんのことです?」
白い帽子の男が言うと、飲み残しの
コーヒーの代わりに、見たこともない色の
林檎があった。

Page 2-5

「なかなか私もやるものでしょう?
貴族の前で披露するほどではありませんが」
「えっ、なぜそれを……」
シェリルは悟った。 この男はすべてを
知っていて、 自分に近づいてきたのだ。
「林檎は、特別にあなたに差し上げます。
一口食べれば、すべて解決するでしょう」
シェリルは何がなんだかわからないまま、
林檎を受け取っていた。

Page 2-6

グレゴールの林檎だ。
シェリルは直感した。
聞いたことがある。
資格のある者は天使になるが、
その資格がない者は…… 死ぬ。
特別な力を秘めたオーパーツだと。
気づけば、 白い帽子の男の姿は消えていた。
食べればすべてが変わる……。
藁にもすがる思いだったシェリルにとって、
あまり選択肢は残されていなかった。

Page 2-7

ーー晩餐会当日。
シェリルは壇上に上げられていた。
見たこともない豪華な建物、 綺麗な衣装の
女性たち、 美味しそうな食事。
そんなものは、緊張の前にすべて
吹き飛んでいた。

Page 2-8

「皆さま！ 国民的人気アイドルで
マジシャンの私が！ 超絶すごいすごすぎる
マジックを披露いたします！！」
貴族たちの白けた視線が、一斉に
シェリルに注がれる。
そして彼女は白い帽子の男から
もらった林檎を一口かじった・・・・

Page 2-9

「皆さま! 国民的人気アイドルで
マジシャンの私が! 超絶すごいすごすぎる
マジックを披露いたします!!」
貴族たちの白けた視線が一斉に
シェリルに注がれる。
そして彼女は白い帽子の男から
もらった林檎を一口かじった……。

Page 2-10

[ページ種別：青]
シェリルは知らない場所にいた。
周りで大勢の子供たちがすすり泣いている。
自分の身体も子供になっていた。
きっとこれは夢なのだろう……。
そうだ。私は魔術師アルブレヒトに
奴隷として売られたんだった……。
突然、 記憶が蘇った。 夢でよくあるやつ。
この子たちも皆、 売られた子供だ。

Page 2-11

[ページ種別：青]
魔術師アルブレヒトは子供の奴隷を使って、
人体実験をしている。 凶悪な魔法生物を
造り出そうとしている······。
大人の足音が聞こえた。 隣の部屋から鍵の
開く音と、男の子の絶叫が聞こえた。悲鳴が
遠ざかって行く。 実験台にされるのだ
きっと次は私の番......。
「私は生きたい…… 生き残りたい。
こんな所で犠牲になるなんていや！」
だから私は――
仲間を売った。

Page 2-12

[ページ種別：青]
アルブレヒトの悪口を言っていた子がいると
それを告げ口し、脱走しようとする者を
捕まえた。自分に懐いていた小さな子も
実験材料として差しだした。
私は最低のクソガキだった。
それでも、……生きたかった。
こんなところで
生を終わりにしたくなかった・・・

Page 2-13

[ページ種別：青]
「アルブレヒト様に忠誠を誓います」
私は、アルブレヒトの助手として、
子供を使った人体実験に協力していた。
アルブレヒトを師と崇め、 奴隷がいくら
犠牲になろうと、何も感じなくなっていた。
いや、何も感じまいとしていたのだ
生き残った私は一心不乱に魔法の技術を
磨いた。

Page 2-14

[ページ種別：青]
生きる価値のない自分が
生き残ってしまった・・・・・・。
その罪悪感から逃れるには目の前の問題に
集中するしかなかった。
だが新たな魔法を覚えるたびに、
心がえぐられていく。
子供たちの憎しみの目が
脳裏に焼き付いて離れない。

Page 2-15

[ページ種別：青]
――そんなある日。
嵐が吹き荒れる夜だった。
シェリルの心は限界をむかえていた。
何もかも投げ出し、 アルブレヒトの
屋敷を飛び出した。
シェリルは逃げた。
アルブレヒトの支配から、
子供たちの憎しみの眼差しから。

Page 2-16

[ページ種別：青]
一心不乱に闇夜を走り抜ける。
振り返ることもせずに、ひたすらずっと
叩きつけられる雨の痛みが、
自分の心を癒してくれる気がした。

Chapter 3

立つ天使 跡を濁さず

Page 3-1

「……ん、なんかすごい夢みたわ。
あれ、ここは？」
意識が現実へ引き戻されていく。
少しづつ目の前の光景に、
焦点を合わせていくと……。

Page 3-2

「ブラボー！！」
突然一人の貴族がそう叫んだ。
するとその声がスイッチとなり、周りの貴族からも歓声が次々とあがった。

Page 3-3

「何これ？ 私……羽が生えてる。 これって天使になったってこと？」
「あはは、ちょっとこれって、
飛べたりしちゃう？」
歓声に応えるかのように、
シェリルは羽を伸ばしてみると……

Page 3-4

「うわっ、マジで飛べるじゃん！
すごっ、ははははっ！」
するとその光景を見た観客は、
さらに大きな歓声をあげて、 シェリルに拍手を送った。

Page 3-5

「そんなバカな……ッ！
本物の天使になっただと！？」
シェリルを吹餐会に招待した貴族は
開いた口が塞がらない。
恥をかかせ、この場で晒しあげ、 帝都に
いられなくしてやるつもりだった小娘が、
拍手喝采を浴びている。
「こんなことがあってたまるか！
警官を呼べ！ あの娘をふん捕まえろ!」
呼び出された警官隊がシェリルを
捕まえようと、ステージへ向かおうとすると
その前に立ちはだかる者がいた。

Page 3-6

「どうしました？
素晴らしいマジックではありませんか！
もっと拍手を送りましょう」
警官たちに声をかけたのは、
白い帽子をかぶった男だった。
警官たちは白い帽子の男を無視して
壇上へ向かおうとする。
そこで、何かに気がつき足を止めた。

Page 3-7

満面の笑みで拍手を送っている男がいた。
「あ、あのお方は皇帝一族の····
な、な、なぜここに！？」
もしやあの男が連れてきたというのか！？
「これほどのマジックが見られるとは！」
高貴な身分の男は、連れの女性たちに
何事かささやき 楽しそうに笑っている。
ここであの娘を捕らえ、不興を買えば
出世の道は閉ざされるだろう
警官隊はすごすごと撤退した。

Page 3-8

貴族は呆然としていた。
周りはマジックだと思っている様だが、
あれは、本物の天使だ。
天使になろうと林檎をかじった者は、
そのほとんどが死ぬと聞いたことがある。
「まったく、 どうかしている……」
貴族は最早、 飛び回り、愛嬌をふりまく
シェリルヘ力なく拍手を送ることしか
できなかった。

Page 3-9

晩餐会も大盛況に終わり
シェリルが帰り支度をしていると
遠くから自分を呼ぶ声が聞こえた。
それは懐かしい声だった。
つい先日まで聞いていたのに、
まるで数年ぶりかのように感じた。
「シェリル！良かった！」
ニッキーが満面の笑みでシェリルに近づく。
そのままふたりはギュッと抱きあった。

Page 3-10

「苦しいよ。 ニッキー」
「何言ってんの!これぐらいさせて。
ほら、 スリスリ」
そういってニッキーはシェリルに、
ほおずりを繰り返した。
「私はシェリルを信じてたよ。
絶対に助けてくれるって......」
「うん......」
その言葉を聞き、
シェリルは一瞬顔を曇らせた。
「アルブレヒト様に忠誠を誓います」
なぜならあの夢のことを
思い出していたからだった。

Page 3-11

「どうしたの？」
心配そうにニッキーが見つめてくる。
するとすぐにシェリルはニヤッと笑って、
「何でもない」と返した。
「友達を裏切らなくてよかった。
あの夢の中の私みたいに……」
「夢? なんの話……？」
「ふふふっ、なんでもな~い」

Page 3-12

「さあ、行こう！」
シェリルの差しだした手を
ニッキーがつかむ。 そのままふたりで
走り出した。
ふたりの手は固く握られ、
明るい笑い声が帝都の大通りに響いた。

Fin.
