Chapter 3

彷徨の章

Page 3-1

ゴゴは、一人で歩き続けた。
昼と夜が何度も過ぎた。
たくさんの人とすれ違った。
二度と会わなかった。

Page 3-2

雨が降らない日が続いた。
緑の敷布は、無残に破れ
二面に褐色の綿をさらす。
森は枯れ、川は消え、畑は千上がる
すさまじい飢餓が巻き起こった。
たくさんの人が死んだ。
もちろん、ゴゴは死ななかった。

Page 3-3

ある日、大きな村にやってくる。
もちろん、そこも飢えている。
ただ、そこは他と様子が違った。
みんな希望を失ってない。
彼らはもしや自分と同じ
不死なのか、とゴゴは思う。
ある男に問うと、 彼は笑って答えた。
「ここには神の鳥がいるんだ」

Page 3-4

飢餓に襲われる村を生かす神の鳥。
ゴゴはその鳥に会いに行く
向かった先は、大きな調理場。
思った通り、ドドがいた。
ドドは何度も殺される。
何度もさばかれ、 蘇る。
切られるたびにドドは鳴く。
ドドの命が、命をつなぐ。

Page 3-5

日が傾いて夜になる。
ドドの料理は、一段落。
調理場から人が消える。
ドドは、調理台から動かない。
すっかり寝入っているようだ。
ゴゴは、そっとドドに近づく。
ドドが目覚めて、ゴゴに気づく。
それでもドドは、調理台から動かない

Page 3-6

「ここにいたら、永遠に食われるぞ」
ゴゴはささやくが、 ドドはそのまま。
仕方ないので引っ張ると
くちばしで激しくつつかれた。
どこからか足音が響く。
誰かが気付いて駆け付けたのだ。
やむなくゴゴは、 ドドを置いていく。
ドドは、調理台に乗ったままだった。

Page 3-7

ゴゴは、村に残ることにする
ドドをこのままにしておけない。
毎日、調理場を覗く。
ドドが体を切られるたびに
ゴゴも切られる感じがした。
けれどドドの様子は、少し違う。
彼は、痛みを嫌がらない。
むしろ誇らしく思うらしい。
ゴゴにはそこが、わからなかった。

Page 3-8

乾いた日々は、まだまだ続く。
ドドもまだまだ食べられる。
ドドはだんだん小さくなった。
皆、そのことを気にしたけれど
ドドは食べられるのをやめない。
ドドのことを知った人々が
世界中からやってくる。
ドドは、みんなに食べられる。
ゴゴはそれをずっと見ている

Page 3-9

ある日、ついに雨が降り出した。
青い毛布を破り捨てたような大雨だ。
しずくが集まり、川になる。
魚も交じって、飛び跳ねる。
人々は喜んだ。
雨を浴び、水をすくって
あちこちに振りまいた。
同じころ。
ドドは最期の時を迎えた。

Page 3-10

ドドはもう、手のひらに収まる
くらいに縮んでいた。
それでもドドは、食べられたがった。
最後の一皿は、淡いスープになった。
飢えた女の子が、母に抱かれて
それを飲む。
女の子は、微笑んだ。
ドドは、二度と蘇らなかった。

Page 3-11

みんな、 ドドの死を悲しんだ。
「やっと雨が降り出したのに」
「神の鳥に恩返しできなかった」
「まだ遅くない。 神の鳥を祀ろう」
「ああ。 この国の守り神として」
みんな、 自分と家族を救った
ドドに心から感謝した。
ゴゴは、それをずっと見ていた。
ドドが、羨ましかった。

Page 3-12

ゴゴは、ずっと死に方を探していた。
不死の自分が生きていることを
証明するために、死のうとした。
きまま
一人で悩み、世界を彷徨い
あらゆるものを見て、知った。
しかし、死に方はわからなった。
だが今、目の前で不死のドドが死んだ。
死ぬことができたのだ。

Page 3-13

ドドは、ひたすら与え続けた。
自分のことは気にせずに
だから、ドドは死ねたのだ。
ゴゴにもそれが分かった。
だけど、これからどうするべきか
ゴゴにはまるで分からない
結局、 自分は何なのだ?
誰が、自分を求めてくれている?
誰も自分を気にしていない

Page 3-14

ゴゴは、白くなった頭を抱える。
脳裏にドドとの別れが浮かぶ。
あの時ドドは、ゴゴをつついた。
何度も何度も繰り返し。
ドドは、きっと死に方を。
知っていたのだ。
けれどもゴゴは、 ドドを蹴った。
ドドを知ろうとしなかった

それぞれの方角に歩きだす。
ゴゴは何かを踏んでいるのに気づく。
それは一枚の羽根だった。

ゴゴは羽根を握り締め
